**业务背景**：为油气钻井作业的自动化服务。核心是「地质导向（geosteering）」——在钻水平井时，实时判断钻头当前钻遇的地层位置，以便把井眼保持在目标储层内。

## 二、任务目标（一句话）

对每口水平井，在「预测起点 PS（Prediction Start）」之后的每个测深点，预测其 **TVT** 值。

- **TVT（True Vertical Thickness）**：真垂直地层厚度，代表井筒在地层柱中的垂向位置（即"钻到了哪层地质"）。它是本赛题的**目标变量**。
- 输入线索：水平井自身的 **XYZ 坐标 + GR（伽马）曲线**，以及配套参考直井（typewell）的 **TVT↔GR** 关系。
- 方法本质：把水平井的 GR 曲线"签名"与参考直井的 GR 曲线做**相关匹配**，从而反推水平井每点对应的 TVT。

## 五、评估指标

主办方 pptx 第 14 页明确：
- 对每口井 PS 之后每个（1 英尺步长）预测点，计算 `dTVT = manualTVT − predictedTVT`；
- 预测质量 = 所有 dTVT 的 **RMSE**。

即最小化预测 TVT 与真值 TVT 的均方根误差。Kaggle API 元信息把指标写作 "Mean Squared Error"，与 RMSE 单调等价，本地 CV 直接用 RMSE 对齐即可。

## 六、主办方给出的关键方法提示（pptx 精华）

1. **GR 签名匹配定位 TVT**（slide 5–7）：水平井 GR 的形态与参考直井 GR 匹配 ⇒ 由匹配位置读出 TVT。
   - GR 签名匹配、TVT 递增/递减 ⇒ 地层在**倾斜（dipping）**；
   - GR 签名恒定、TVT 恒定 ⇒ 地层**近水平（flat）**。
2. **水平井自身 GR 分辨率更高**（slide 9）：PS 点之前水平井已知的 GR + TVT，往往比参考直井的 GR 更适合用来标定 PS 之后的地层——优先用"本井 PS 前段"做相关，再外推 lateral 其余部分。
3. **邻井/偏移井（offset well）辅助**（slide 12–13）：地层倾角在相邻井之间行为相似；水平钻进的**方位角（azimuth）**影响预期的地层倾向。可利用 XYZ 坐标找邻井，借其倾角先验来约束当前井预测。
4. 单位统一为英尺；GR 存在 NaN 需处理。

## 七、建模要点小结（供后续方案参考）

- 这是一个**逐点回归**问题（目标 TVT，连续值，RMSE），但强烈依赖**序列/曲线相关**结构，而非普通表格特征。
- 本质是**曲线对齐 / 测井相关（log correlation）+ 倾角外推**：把水平井 lateral 段的 GR 序列，动态对齐到参考直井（或本井 PS 前段）的 GR-TVT 曲线上。
- 关键先验：TVT 随 MD 通常**平滑连续**（地层缓变），可作为强正则；相邻井倾角相似。
- 验证策略：按**井**做分组交叉验证（GroupKFold by well），模拟"整口新井"的泛化；每口井内部用 PS 点切分，本地复现"PS 后外推"的真实评测口径。
- 注意数据泄漏：预测某井 PS 之后的点时，不能使用该井 PS 之后的任何真值信息。
