# v7：CatBoost 多种子袋装

复用 v3 的 `seed=42` 预测，新增一套完全相同的 `seed=2026` 五折模型，比较概率平均与 rank 平均。它衡量的是随机性降方差收益，不改变特征或模型族。

运行：

```bash
/opt/anaconda3/bin/python v7_catboost_bagging.py
```

## 结果

- seed=2026 单模 OOF：`0.967948`
- 两个种子的秩相关性：`0.998242`
- 概率平均 OOF：`0.968132`
- 相对 v3(seed=42)：`+0.000167`
- 概率平均略优于 rank 平均 `0.968132`，因此作为 v8 的 CatBoost 基线

结论：同模型多种子只能带来小幅降方差收益，但这次增益超过 `0.0001`，可以保留。
