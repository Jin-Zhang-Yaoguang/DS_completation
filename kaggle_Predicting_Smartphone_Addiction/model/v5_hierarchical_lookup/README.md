# v5：层级查表/平滑模型

## 假设

数据中的数值大量重复，精确取值可能来自有限的合成模板。模型对每个字段建立“精确值 → 数值分位区间 → 全局概率”的经验贝叶斯层级，并用固定强度收缩，避免低频精确值过拟合。

## 防泄漏

- 训练行的统计量来自内层 5 折 OOF 编码，整折标签均不可见。
- 验证集和测试集只使用当前训练折的标签统计。
- 每个外层训练折内标准化全部输入，降低正则化尺度失衡和优化困难。
- 所有模型沿用 `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`。

运行：

```bash
/opt/anaconda3/bin/python v5_hierarchical_lookup.py
```

## 结果

- OOF AUC：`0.958196`
- 相对 v3：`-0.009769`，0/5 折胜出
- 与 v7 的 OOF 秩相关性：`0.976779`
- v8 交叉拟合在五折中均未选择该模型，最终权重为 0

折 4/5 的 Logistic Regression 达到 300 轮上限；标准化前后 OOF 仅变化约 `0.000009`，且 v8 对它给出零权重，因此没有继续为该弱基模型调参。

结论：精确值查表本身包含有效信号，但纯加性组合无法表达变量之间的非线性交互，不作为单独提交候选。
