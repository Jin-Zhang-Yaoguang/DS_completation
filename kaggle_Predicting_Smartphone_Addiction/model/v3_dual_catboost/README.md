# v3_dual_catboost

CatBoost 连续值/精确值双重表示候选：

- 9 个数值字段保留连续值，用于学习平滑趋势；
- 12 个原始输入字段复制为字符串类别，让 CatBoost ordered statistics 学习精确值关联；
- 保留 v2 已验证的三个时间预算特征；
- 使用与 v1/v2 完全相同的 5 折 `StratifiedKFold`。

## 单模与融合准入门槛

- v3 单模 OOF 至少比 v2 高 `+0.0005`，且至少 4/5 折提升；
- 与 v2 的 OOF Spearman correlation 低于 `0.995`，才认为有融合多样性；
- 融合必须通过外层折留一的权重选择，并至少比最佳单模高 `+0.0001`；
- 未满足门槛时，不提交融合文件。

## 运行

```bash
cd kaggle_Predicting_Smartphone_Addiction/model/v3_dual_catboost
python v3_dual_catboost.py
```
