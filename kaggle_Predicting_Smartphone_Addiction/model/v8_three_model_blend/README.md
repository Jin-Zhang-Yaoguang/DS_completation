# v8：三模型交叉拟合融合

融合方案在看到 v7 结果前预注册：

- 每个 held-out 折只用其余四折选择模型和权重。
- CatBoost 基线从 v3/v7 中选择。
- 最多从 v2、v5、v6 加入两个模型，总模型数不超过 3。
- 每步新增权重限制为 0%–30%，步长 2%。
- 只有 cross-fitted OOF 相对最强 CatBoost 单模型提升至少 `0.0001` 才生成提交。

运行：

```bash
/opt/anaconda3/bin/python v8_three_model_blend.py
```

## 结果与提交

- 五个 held-out 折全部提升，单折增益 `+0.000151` 至 `+0.000285`
- 最终权重：v7 `66.08%`、v6 `28.32%`、v2 `5.60%`
- cross-fitted OOF：`0.968358`，相对 v7 `+0.000226`
- 固定最终权重 OOF：`0.968359`
- Public LB：`0.96954`
- 提交 ref：`55577566`，状态 `COMPLETE`

v5 虽然相关性最低，但单模损失过大，五折均得到零权重；多样性只有在基础精度足够时才有融合价值。
