# v6：高分辨率 LightGBM

在 v2 的连续值和时间预算表示上加入 v5 的严格折外层级编码，并把直方图分辨率提升到 `max_bin=1023`。目标是验证树模型能否利用精确值统计之间的非线性交互。

运行：

```bash
/opt/anaconda3/bin/python v6_highres_lgbm.py
```

## 结果

- OOF AUC：`0.967373`
- 相对 v3：`-0.000593`，0/5 折胜出
- 与 v7 的 OOF 秩相关性：`0.990778`
- 单模略弱，但在 v8 的五个 held-out 折中都被选中，最终融合权重 `28.32%`

实现过程中发现并修复了一个重要陷阱：leave-one-out 编码与组频次共同输入树模型时，树可以从自排除差异反推标签。最终版本改为真正的内层 5 折 OOF 编码。
