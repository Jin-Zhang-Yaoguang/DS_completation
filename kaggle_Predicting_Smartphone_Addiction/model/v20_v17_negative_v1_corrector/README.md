# v20 — v17 的负向 v1 误差校正

## 假设

现有 11 个模型高度相关，继续平均会稀释强信号。论坛的大规模统一 OOF 实验表明，
低容量、低相关模型更适合作为带负系数的误差校正，而不是正权平均成员。

本实验锁定一个保守公式：

```text
1.075 * v17 - 0.075 * v1
```

它不训练二层模型、不混入公开提交，也不在 11 模型上拟合权重。测试预测最后只做
百分位 rank，避免负值 clipping 产生并列；ROC AUC 对该单调变换不变。

## 验证门槛

- 使用与实际部署一致的 v8 固定权重重建 v17 OOF；
- 总体 OOF 增益至少 `0.0001`；
- 5/5 折同向；
- 按 train/test 缺失模式做密度比加权后，三种平滑口径仍同向。

达到门槛才允许提交；结果见 `cv_results.json`。

## 结果

- deploy-aligned OOF：`0.968657 -> 0.968793`，增益 `+0.000135`；
- 五个折全部提升；缺失模式重加权后的增益稳定在 `+0.000129~+0.000130`；
- Kaggle Public LB：`0.96998`，ref `55719089`；
- 相对 v17 Public `0.96977` 提升 `+0.00021`，成为当前 best。
