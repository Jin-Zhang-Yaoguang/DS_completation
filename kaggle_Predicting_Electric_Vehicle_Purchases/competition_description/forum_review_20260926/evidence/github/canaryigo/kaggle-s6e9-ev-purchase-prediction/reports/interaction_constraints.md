# income解像度とinteraction制約の切り分け

以下は単体FのOOF、順にseed42 / seed20260918。

- 元F：0.94605253 / 0.94605825。
- incomeだけ高解像度：0.94606548 / 0.94605083。
- 高解像度 + constraints：0.94615852 / 0.94615019。
- 全max_bin=1024 + 同じconstraints：0.94615563 / 0.94614755。

高解像度化だけでは別seedで改善しなかった。制約を維持して1024へ戻した差は約-0.000003であり、主な改善はinteraction制約側にあった。

制約は元の12特徴量ごとにraw・digit・TE・frequency・original平均をまとめ、木が別の元特徴量グループを交差利用しないようにする。元特徴量単位の加法的な構造を強めるもので、同じグループ内の複雑な非線形性は禁止しない。

Public 0.94628の提出は、seed42・制約F・RealMLP10%・追加rank段階を含む。一方、旧Public 0.94635はseed20260918・元F・RealMLPなし。このPublic差を制約F単独の悪化と読むことはできない。

最後はPublic bestの構造を維持し、F枠だけを元F/制約Fの固定50:50へ変更。最終ensembleは両seedの5/5foldで改善した。50:50以外のhybrid比率は探索せず、seed20260918の結果をPublic 0.94636として記録した。
