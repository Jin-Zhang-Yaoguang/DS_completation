# 旧线上算法 C 的同外层对照预注册

状态：DESIGN_PREPARED_NOT_STARTED。这是补齐旧配方基准的条件式复核，不是新参数搜索；不计 C01，不生成实际 test 或提交。

## 发现与唯一问题

当前 E2E A/B 对 CPU 原子采用 F 内90/10早停后全F重训；旧 V100 的 V80/V85 在F训练、H早停，随后以同模型预测H/test。故 A不是旧线上算法完整对照。当前冻结运行保持原样；本补充只回答：固定候选B能否优于同外层重建的旧算法C？

在任何真实A/B评分尚不可用时冻结本规则。数据属于历史开发数据，不称新盲测。

## 固定角色与门槛

- B是唯一升级候选：新F内早停CPU配方 + CT五折平均。
- A是新F内早停CPU配方 + CT全量refit，只解释CT推断方式。
- C是旧H早停CPU配方 + CT全量refit，为线上V100算法基准。
- 首先要求既有完整B-A gate通过：整体增量严格大于0、5/5外层正向、最终pipeline成功且独立复算PASS。未通过时本C训练不启动。
- 只有B-A通过，才允许一次性启动C CPU作业。C完成后一次性报告B-C为主要新增比较、A-C为解释性比较，同时保留B-A。B-C须整体严格大于0且5/5为正，并独立复算通过，才可另立实际test重建合同。研究晋级仍单列增量至少0.0001及5/5。
- A-C不用于B失败后临时改选A，不在看到分数后更换基准、切片、阈值或权重网格。
- 所有验证cache自身allowed_for_submission=false。提交仍须新全局匹配产物和提交前实时检查。

## C的精确算法

- 共用既有E2E的5个outer T/U，seed42437和splits.npz SHA；T内V80 40折seed104395303、V85 40折seed42，原子TE和模型种子与既有E2E相同。
- 对每个原子，F=T\H。严格TE只由F标签生成；训练F、早停评估H；保留同一个早停模型预测H和U，不以F内部早停替代，不二次refit，不从A保存模型中挑树前缀。
- H标签可用于选轮，因为H属于最外层T；U标签不进入训练、早停、参数或元层选择。接口明确区分H与U，不套用A的query标签全不可用标记。
- 复用冻结static/strict TE实现和原数据；static允许合同内的无标签train/test统计。无法直接验证身份的编码重新由同F构造。V80保持113列float32，V85保持148列float64混合静态精度合同。
- 模型参数直接绑定原V80/V85 frozen config与已有E2E家族参数；均8线程。每outer保存两家族各40原子OOF与U均值，共400个最终CPU模型、400次fit；逐原子保存模型、预测、来源/身份/参数/选轮范围manifest。
- C复用已经完成归档并核验的相同T/U CT OOF和U fullfit缓存，不重复GPU训练。
- C独立用自己的V80/V85 OOF与同T的CT OOF重新拟合冻结fit_v100_meta；只传T标签。V90元折、ECDF、网格与并列规则与原实现相同，不能沿用A/B的元权重。
