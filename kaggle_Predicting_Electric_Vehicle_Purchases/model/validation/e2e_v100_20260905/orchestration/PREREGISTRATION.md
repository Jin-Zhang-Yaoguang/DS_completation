# 同一训练实例的完成后处理

只衔接已经启动的 CPU PID24797 和私有 Kaggle CT version1，观察、下载、完整审计、装配及评分。沿用所有已冻结的科学协议，不训练模型、不推新kernel、不提交比赛。

启动前冻结本脚本、下载器、CPU/GPU/assembler配置与回执SHA，绑定CPU进程创建时间，防止PID复用。轮询CPU存活与当前进度，GPU状态每120秒一次；查询失败只记录观察失败，继续查询同一kernel，不能当成训练失败或重复推送理由。

GPU成功后用独立下载器核验源码/最终监督状态再落到remote_output。CPU必须完整成功且400个原子齐全，随后依次执行冻结assembler的audit、assemble、score。score自带独立verify，不重复调用额外verify。任何阶段非零退出、资源超限或证据漂移都停止本后处理，保留日志及失败状态；不会重启训练、修改门槛或覆盖已有结果。

监督器总墙钟15小时；GPU状态查询每次上限60秒；下载上限15分钟；audit/assemble/score每项上限1800秒、16GiB子进程树、2线程。监督器自身轻量运行。原CPU12小时/24GiB和GPU7200秒/24GiB限制仍独立有效。

科学完成只认score结果与原冻结门禁；后处理成功表示结果可审阅。实际test构建和用户条件授权下的比赛提交仍是下一个独立步骤，不能由本程序执行。所有状态更新原子写入，整个流程只有一个flock实例。
