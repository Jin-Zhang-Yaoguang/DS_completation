# v100 v90 + CTBoost 嵌套小融合

## 预注册

- 实验 ID：`v100_v90_ctboost_nested_cv_blend`；C01 第 17 个正式关闭项候选；类型为
  2 成员小融合。
- 来源诊断已冻结：私有 GPU CTBoost seed42 五折 OOF `0.9459617209236499`，
  与 v90 的 fit-only mid-ECDF 嵌套融合诊断为 `0.9463981465241269`，相对同口径
  v90 `+0.0000271597585448`、5/5 元折为正。
- 唯一问题：把来源诊断按正式产物 schema、完整来源校验和同一嵌套元折合同封装后，
  是否仍不弱于当前数值最佳 v95 OOF `0.9463838901455106`，从而满足用户明确给出的
  提交校准条件。
- 成员固定为 v90 与 CTBoost；每个 seed42 元训练折只在固定网格
  `0, 0.025, ..., 0.5` 中选择 CTBoost 权重，mid-ECDF 只在该元训练折拟合；OOF
  由五个元 holdout 拼接。test 权重和两个 ECDF 状态只在完整 OOF 上重新拟合。
- 研究晋级门槛不变：相对同口径 v90 至少 `+0.0001` 且 5/5 元折提升。低于该门槛
  仍为 `REJECT`，不得进入后续融合池。
- 用户提交覆盖：若正式嵌套 OOF 不低于 v95，允许消耗 1 个提交名额，仅用于检验
  线下到 Public 的偏差；线上结果不能反向改变权重、研究决策或候选资格。
- 禁止使用 Public LB 调权、扩网格、加入第三个成员、读取 CTBoost test 标签（不存在）、
  把完整 OOF 回代分数冒充嵌套 OOF。
- 预算：900 秒、12 GiB、1 次提交。

正式运行前必须通过 hash-only audit、合成 smoke 和测试；运行后必须再执行完整 verify。
