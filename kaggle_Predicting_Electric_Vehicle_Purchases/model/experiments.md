## 数据核验要点（2026-09-03）

- 训练集 668,665 × 15，测试集 286,571 × 14，提交样例 286,571 × 2；`id` 唯一且 train/test 无重叠。
- **无缺失值**（与 S6E8 不同，无需插补策略）。
- 目标 `Will_Buy_EV` 为字符串 `Yes`/`No`，正类 `Yes` 占 17.46%，中度不均衡；提交列需填 `Yes` 的概率。
- `sample_submission.csv` 中 `Will_Buy_EV` 全填 0.174645，即训练集正类先验。
- 单变量强信号：`Subsidy_Available=No` 正类率仅 0.58%，`Range_Anxiety_Level=High` 仅 0.14%、`Medium` 4.17%；`Environmental_Concern_Level` 与 `Annual_Income_USD` 在正负类间均值差异显著。
- 训练集内无精确重复行，测试集无与训练集完全相同的特征行。

## v1 结论（2026-09-03）

- 特征重要性（gain）：`Environmental_Concern_Level` > `Subsidy_Available` > `Annual_Income_USD` > `Range_Anxiety_Level`，前四项占绝大部分增益；`Gender`、`Current_Car_Type`、`City_Type`、`Number_of_Cars_Owned` 增益极低。
- `Annual_Income_USD` 的 split 次数最多（约 10k/折）但 gain 排第三，说明模型在收入上做了大量细粒度切分，与讨论区报告的收入硬阈值/单值伪影一致，收入的精确值与细分箱统计特征是下一步优先方向。
- 线上分数与 OOF 几乎一致，adversarial validation 结论（train/test 同分布）得到印证，后续以 OOF 为准做方案取舍。
- 与榜首差距约 0.0047，公开 notebook 用折内特征工程 LightGBM 也停在 0.9417，说明提升需要来自伪影级特征或模型类型（CatBoost 精确值表示）而非常规调参。

## 收入伪影探索（2026-09-03，为 v2/v3 设计依据）

折外目标编码（TE）单特征 AUC，5 折、平滑 20：

| 键 | 唯一值数 | TE AUC | 备注 |
| --- | ---: | ---: | --- |
| `Annual_Income_USD` 原值 | 13,214 | 0.6704 | 单调排序 |
| 收入精确值 | 13,214 | 0.7107（平滑 5 为 0.7126） | 精确值携带原值之外的信息 |
| 收入 // 100 | — | 0.7033 | 100 分箱仍保留大部分信息，更粗的分箱迅速衰减 |
| 收入 + `Subsidy_Available` | 21,519 | 0.8262 | 联合键 |
| 收入 + `Environmental_Concern_Level` | 43,228 | 0.8611 | 联合键 |
| 环保等级 + 补贴 + 焦虑 | 30 | 0.9227 | 低基数组合，树模型可自行学到 |
| 环保等级 + 补贴 + 焦虑 + 家充 | 50 | 0.9236 | 同上 |

其他数值列的精确值 TE 相比原值几乎无增益（`Age` 0.547 vs 0.506，其余 <0.02），伪影集中在收入列。

结构性事实：

- 收入 = 30,000 单值占 9.21% 行（买率 4.4%）；收入尾数为 1000 倍数的行几乎都是这个单值；尾数为 100 倍数占 10.1%（买率 5.4%）。
- 训练集 97.94%、测试集 97.92% 的收入值落在原始数据集（8,915 个唯一值）的取值集合内，说明生成器大量复制了原始收入值；测试集 99.42% 的收入值在训练集中出现过。
- 收入 ≥ 170,537 的 393 行全为 Yes（测试集 156 行）；收入 38k–42k 的 1,277 行买率 0.16%；`Environmental_Concern_Level = 1` 且无补贴的 59,674 行仅 10 个 Yes。
- v1 OOF 在收入 = 30,000 子集的 AUC 仅 0.9153（整体 0.9418），是最薄弱区域；收入低频值（频次 <10）子集反而 AUC 0.946。

由此确定：v2 在 v1 基础上加入折内 TE（收入精确值、收入//100、收入×补贴、收入×环保等级）与无标签结构特征（收入频次、是否在原始集、尾数指示）；v3 用 CatBoost 对全部数值列做连续值 + 精确值字符串双重表示，不手写 TE。

### 残差分析（v1 → v2 的增益来源）

- 增益几乎全部来自环保等级 / 补贴组内的排序：within-Env 配对加权 AUC 0.8644 → 0.8749（`+0.0105`），within-Subsidy `+0.0064`，整体 `+0.0038`。
- 按收入频次分层：频次 <10 的行增益 `+0.0074`，10–100 为 `+0.0064`，100–500 为 `+0.0027`，≥500 仅 `+0.0006`；收入 = 30,000 子集（9.2% 行）AUC 0.9153 完全没有改善，因为该子集内收入无信息。
- v2 概率校准良好（各概率区间实际率与预测均值一致），不存在被欠拟合的确定性区域。
- 推论：剩余可挖掘的主要是目标编码本身的估计噪声（每个收入值平均 50 行、收入×环保键平均 15 行），以及模型对同一信息的不同估计方式带来的融合增益（v2/v3 秩相关 0.9908 仍有 `+0.00023`）。
