## 主要结论

**纯 ECDF 全量拟合和五折平均的差异太小，不值得继续训练这个方向。**固定原有各折权重，只改变 ECDF 拟合范围：

| 对照 | test Spearman | 百分位秩位移 p99 | 最大预测差 | 冻结差异门槛 |
| --- | ---: | ---: | ---: | --- |
| V90 五折 ECDF → 全量 ECDF | 0.999999999982 | 0.000006979 | 0.000010457 | 未达 |
| V100 五折 ECDF → 全量 ECDF | 0.999999999958 | 0.000010469 | 0.000014409 | 未达 |

V90 同时把平均权重 0.54 改为训练 OOF full-fit 0.55，test Spearman 仍有 `0.9999998419`，秩位移 p99 `0.0005793`。V100 完整 full-fit 0.20 与五折均值合同（权重均值 0.21）的 Spearman 为 `0.9999996124`、p99 `0.0009108`，也未达预注册差异线。V100 差异几乎全部来自 0.20/0.21，而非 ECDF 本身；不能因此扫权重或依据 test 选 0.21。

**CTBoost 有更明显的 OOF/test 分布差异，但尚不能证明全量 refit 伤害 AUC。**

| 模型 | OOF/test KS 效应量 | test−OOF 均值 | test/OOF 标准差比 |
| --- | ---: | ---: | ---: |
| V80 | 0.0035751 | +0.0000711 | 0.999161 |
| V85 | 0.0042892 | +0.0000338 | 0.999115 |
| CTBoost | **0.0337114** | +0.0001264 | 1.000938 |
| V90 | 0.0031709 | +0.0014417 | 0.996756 |
| V100 | 0.0042856 | +0.0004672 | 1.001331 |

V90/V100 是秩混合分数，其均值不能解释为买车率或概率校准误差。CTBoost 低概率端差异较大：1% 分位从 `0.0000886091` 变为 `0.0000569300`，10% 分位从 `0.0005433435` 变为 `0.0003883870`；50% 分位 `0.0159650 → 0.0164072`。这不是普遍的预测尺度坍缩，也没有 0/1 饱和；只有 12 个 test 分数低于 OOF 最小值（0.00419%）。

CTBoost 当前 OOF 来自五个 80% 训练模型，test 来自一个全量模型。没有保存五个原子 fold 的 test 预测，不能在现有文件中构造与全量 refit 严格配对的替代结果。训练量、模型平均、人口分布三者混杂，KS 不是因果识别。

**OOF 的模型分歧比 test 大，这会影响对融合多样性的估计。**V80/V85 Spearman 从 OOF `0.996675` 升到 test `0.998460`，平均秩分歧从 `0.015786` 降到 `0.010525`；V90/CTBoost 从 `0.994885` 升到 `0.996297`，平均秩分歧从 `0.018919` 降到 `0.015833`。这与平均预测降低方差相容，也可能受样本分布影响；不能从 test 反推新权重。

## 固定后续建议

1. `ECDF_ONLY: NO_GO`。保留证据，不扩大网格、不因微小差异训练新版本。
2. `CT_INFERENCE_CONTRACT: HYPOTHESIS_READY_NOT_RUN`。在完整 V100 算法的同一端到端外层验证中，只比较 CTBoost 全量 refit 和已有五个 fold 模型的均值；两臂共享原子 OOF、元变换和训练侧权重。不得把 test 分布校正或分位匹配视为改进。
3. 该对照同时提供一次完整 V100 的端到端复核。两臂原子模型都必须重新限制在各外层训练块，LightGBM 早停内移。具体设计见 `END_TO_END_CONFIRMATION_PLAN.md`。
4. 现有 V100 `0.9463981465` 继续保留为开发参考。新确认的低分不能解释为模型突然变弱；高分也不能单凭与旧 OOF 相减就声称改进。主要判断只看新协议下两臂的配对差值。
