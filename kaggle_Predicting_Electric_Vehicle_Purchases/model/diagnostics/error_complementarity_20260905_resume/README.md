# 固定切片错序与互补性审计

本报告只分析已有 OOF，不训练、不调权、不产生新预测。预注册见 `preregistration.json`；可复跑程序为 `audit.py`，完整分桶及贡献见 `evidence.json`。

|---|---:|---:|---:|---:|
| v80 | 0.9462406110 | 0.7867576226 | -0.0005402601 | 0/5 |
| v85 | 0.9462702274 | 0.7867721712 | -0.0005257114 | 0/5 |

| v100 | 0.9463981465 | 0.7872978827 | +0.0000000000 | 0/5 |

主切片为环保等级 4/5、有补贴、低里程焦虑，共 162,533 行，正样本 95,479。v100 在该切片组内错序占全体正负对错序的 39.42%，全体 AUC 错序质量贡献 0.02112955。

既有原子预测直接支持局部专家的门槛：NO_GO，不能据此创建局部换权候选。新表示诊断优先级：有：主切片错序集中超过预注册 25%。

`within_global_error_mass` 是该组内错序对数除以全体正负对数；两类 cross 字段分别计算正样本在组内、负样本在组外以及相反方向，因此能检查局部排序与跨组排序的取舍。多分组的 within/across 总质量严格守恒；二值切片的跨组对在两个组说明中重复出现，不得再把组说明相加。

下一项可证伪假设：全局模型在高环保、有补贴、低焦虑区域分配的模型容量不足；仅在这个预先固定区域训练一个独立局部专家，使用外层训练折内的交叉拟合输出学习连续残差修正，可能改善该区间内排序。应保持全局严格模型、切分与其他特征不变，以同预算全局对照隔离“局部容量”这个主要变量；门控条件由原始无标签字段固定，不根据真实标签挑错行。先做固定五折诊断，同时要求总体 AUC 净增、主切片组内净增与跨组没有抵消，达到新预注册门槛才考虑完整验证。本报告支持研究优先级，尚不证明错误可以学习；不能直接依据这里的既有预测换权，也不能重复已经否定的收入 TE 平滑/交叉键。

v100 相对原始 v90 OOF 的精确总体增量为 `+0.000026071948`，分解为：主切片组内 `+0.000009545686`；正样本在主切片、负样本在外部 `+0.000030543597`；正样本在外部、负样本在主切片 `-0.000022932908`；切片外组内 `+0.000008915572`。两种跨组方向会明显互相抵消。这里比较的是原始两份 OOF，区别于 v100 正式报告再次 mid-ECDF 变换后的同口径 v90 基准增量 `+0.000027159759`。

辅助切片中，收入 30,000 的 61,605 行组内错序仅占全部错序约 `0.39%`，不支持因为这个值常见就把研究主线押在该单值。收入频次 100–499 桶内错序占约 `31.12%`；这些与其他分组有重叠，不能相加。

固定抽样正负对显示 CTBoost 能修复约 `5.83%` 的主切片 v100 错序质量，但同时破坏更多原本正确的排序，精确净增量仍为负。抽样量仅 250,000 对/范围，对 `0.00001` 级净差存在明显 Monte Carlo 误差，部分抽样净差会与精确计算符号相反；因此只用抽样值描述错误交集，用精确值决定方向是否通过。

校验：来源 OOF SHA、CTBoost ID/目标/seed42 fold、概率合法性、精确 AUC 对照和错序贡献守恒均通过。耗时 16.23 秒，peak RSS 0.963 GiB，2线程；未修改注册表或历史文件。

局限：这些数据已用于历史选模，本诊断不能变成新的无偏 CV 结论；5个seed42桶不是所有模型相同训练折。抽样修复/破坏率只描述互补性，不能证明推理时能够识别哪对样本应由哪个模型负责。
