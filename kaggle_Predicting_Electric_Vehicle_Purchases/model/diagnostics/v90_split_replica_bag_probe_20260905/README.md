## 预注册

- 实验 ID：`TEMP_V90_SPLIT_REPLICA_BAG_NESTED_META_SEED42`。
- 唯一问题：已存在且来源严格的 v81(split7)、v82(split2026)、v96(split42) 三个
  v80 配方复刻先固定原始概率等权成一个 family bag，能否给 v90 增加切分方差之外的
  稳定排序信息。
- v90 已含 v80+v85；候选 bag 明确不含 v80，避免同一原子预测作为父子重复计权。

  `0, 0.025, ..., 0.5` 网格选择整个 family bag 的权重；只输出诊断证据，不保存
  OOF/test。
- 正式化门槛：family OOF 不低于 `0.9462`，且嵌套融合相对同口径 v90 至少
  `+0.0001`、5/5 元折提升。未通过则关闭，不拆开搜索三成员权重。
- 当前提交参考线为 v100 OOF `0.9463981465241269`；诊断本身不提交，即使数值达到
  参考线也必须另立正式版本。
- 预算：120 秒、8 GiB、0 次提交；不使用 Public、test 或确认 seed 调权。
