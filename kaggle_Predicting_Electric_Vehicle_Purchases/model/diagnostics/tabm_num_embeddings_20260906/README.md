## 冻结设计与边界

- 两臂使用严格 V85 148 维特征；外层五折 seed42，训练折内五折 TE；标准化统计只取训练折并裁剪到 [-12,12]。
- TabM-mini k16、3 blocks、width256、dropout0.15；数值嵌入 LinearReLU d8。24 epoch 上限、patience4、AdamW lr0.002、weight decay0.0003、batch2048；训练种子和每轮批次顺序配对。
- 门槛事前固定：合并 OOF 增量至少 +0.0001，5/5 折正向，候选 AUC 至少0.9452。第一项未过，不能以平均折分替代。
- 两臂参数量分别176,208和460,368。这里只检验该嵌入配置，未完全分离表示机制与模型容量。
- 外层验证参与早停，属于开发诊断，不是独立盲测。没有与旧 V100 做完整算法对照。
- 官方 tabm0.0.3 与 rtdl-num-embeddings0.0.12 冻结在本目录 deps，来源及 SHA 见 dependencies.json；全局 Python 环境未改。

## 为什么五折都提升，合并增益却小

平均折 AUC 增量为 +0.000186243，而合并 OOF 增量仅 +0.000046673。AUC 包含不同折正负样本之间的比较，因此两者不等价。

25 类样本对的只读分解表明：同折样本对约占20%，其条件 AUC 增量 +0.000186242，对整体贡献 +0.000037248；跨折样本对约占80%，其条件 AUC 增量 +0.000011781，对整体贡献 +0.000009425。

这是算术归因，与不同折模型的分数尺度或校准差异相容，未证明校准是唯一原因，也未证明任何校准方案有效。测试时对同一行平均五折预测与拼接 OOF 不同，不能据此声称真实测试推断存在同样损失。没有拟合校准器、变换预测或按结果换指标。
