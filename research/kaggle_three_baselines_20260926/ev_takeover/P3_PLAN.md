# P3：在原 V100 层级内替换 V85 家族

总负责人于 2026-09-26 11:57 UTC 轮次制定。在运行任何 P3 新分数前冻结。目标仍是线上 Public AUC 超过 V100 的 0.94635，未完成目标不因两条固定配方关闭而结束整体工作。

## 新证据与区别

P1 完整 40 折及复核已给出：原 V85=0.9462702273556288，grouped V85 B=0.9463315543380929，固定同家族平均 C=(V85+B)/2=0.9463785735522274。C 相对原 V85 提高 0.0001083461965986；P1 最外层的固定 M=(V100+C)/2 却为0.9463941900980236，未超过V100的0.9463981465241269。

源码线索：V100 输出经过两层 fit-only mid-ECDF 与权重拟合，C 保持原始概率。P1 将两种表示直接放在最外层平均，同时重复给 V85 家族权重。本次假设是：在原层级内部替换 V85 家族，经原有 ECDF 和元训练程序再组合，能够保留已确认的家族内增益。表示和重复计权是否是 P1 失效原因尚未证明，不能把该解释写成结论。

这是一项组合位置与成员血缘实验。P1/P2 原配方仍关闭，不改原分组、训练超参、种子、C 的50:50比例，也不扫描 P1 外层混合权重。P3 不引入任何新基模型训练或外部预测。

## 唯一候选，先做结构审计

1. 冻结原 V100、V90 的实际源码与输入 OOF/test、P1 C 的 OOF/test、原 V80/V85/CT 来源与行标识。
2. 读取函数与调用顺序，列出原 V100 的两层 ECDF、训练折、权重网格、tie-break、test 推断方式和成员血缘。若发现历史已有同配方替换试验，先举证，不换名重跑。
3. 原基准忠实重放：V80 + V85 -> V90，V90 + CT -> V100。重放 OOF/test 必须与存档在既有数值容差内一致。基准不能换成弱版或新 CPU 早停版。
4. 唯一 P3 候选：**把 V90 输入中的原 V85 替换为 C=(原 V85 + P1 grouped V85)/2；V80 不变；重新执行原 V90，再与原 CT 重新执行原 V100。** 原网格、tie-break、ECDF、meta fold、test 推断保持完全一致。权重仅由既有元训练算法在元训练折里拟合，没有人工选择新的权重网格。
5. 不额外测试 B-only 替换、不同 C 系数、V90/P3 后融合、多种排名转换等。若唯一候选失败，关闭该组合位置配方。

此计划授权在新的研究目录中单独评估 P1 C 的内部替换，不把未晋级的 B/C 自动放回通用合格池。作为条件性的独立小融合实验，成员血缘和原 P1 未过门槛结论必须保留。
