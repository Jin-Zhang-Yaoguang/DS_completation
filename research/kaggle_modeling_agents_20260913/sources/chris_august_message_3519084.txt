Memory is important. After every 4-12 hour campaign, I had them write down all their new discoveries. This is gold. I can show a new model over 50 discovery.md files containing pure brilliance. My team did this in NeuroGolf comp 1st place too.
I like to use 1M or more token context and never force a context compact. Because I want it to have as much memory as possible. I can also tell agents to reread all the discovery files. Agents do tens of thousands of experiments over days, they need memory so they don't repeat themselves and so they can continue searching from all avenues that have more potential. In general, I use max thinking when i want break throughs or doing important EDA work or feature engineering detective work. For more routine coding, we can reduce the thinking.
