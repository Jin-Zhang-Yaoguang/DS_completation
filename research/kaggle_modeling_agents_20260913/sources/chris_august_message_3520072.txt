These are great suggestions. I basically do everything or try to :-)
(1) yes i use all public info both in this comp and previous comps (2) yes i use my domain knowledge to help
But I also run agents without giving them this first. In the same way that the best human Kaggle team is where humans work independently first, i do this with my agents. I usally begin a new agent with "Here's the data build a strong model". And let it try from nothing. Then i give it some clues and it tries again. I repeat this for different amounts of time. Then finally i give it public knowledge and my knowledge and say to combine the new ideas with its ideas to do better. I add all of its work to the ensemble (i.e. models it built without knowledge and models it built with knowledge)
And then there are lots of hybrids to this. I then ask a smart agent (who has been working for a while) to make an introduction starter folder for another agent and only give it some info inside. So maybe it gives it some public ideas and some domain knowledge ideas. But not everything. And the new agent starts from that.
So there are lots of way to apply the no knowledge, versus limited knowledge, versus all knowledge tricks and i try them all.
