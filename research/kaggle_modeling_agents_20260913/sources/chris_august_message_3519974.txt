My advice is going to sound circular and paradoxical. The best way to use agents is to ask agents how to use agents!
Get one agent up and running. Preferrably one of the best like GPT 5.6 or Fable 5.1. Then have the agent do some work itself (i.e. EDA, build models, etc) because just like humans, agents learn from doing. (They have a 1 million token context which is their previous conversation, thinking, and tool calling history. This gets appended to each new prompt we ask and represents their working memory). Afterward this agent is really smart.
Next, ask the agent. "Can you help me use agent XYZ? Can you create a folder of resources and give me instructions and a prompt to start agent XYZ?". That is how I incorporated using ChatGPT and the 6 models from NVIDIA Inference Hub efficiently.
Lastly, after having agents work for an N hour campaign, always have them write what they did and what they learned afterward. Every agent needs to continually write MD files logs of what it is doing and what it did. Records, records, records (as an accountant may say). These are invaluable. At one point GPT5.6 hit a plateau and couldn't improve its single model. I had Fable 5 read its logs. Then Fable 5 told me what to tell GPT5.6. After that GPT5.6 built a better single model than Fable 5! Mind blown!
