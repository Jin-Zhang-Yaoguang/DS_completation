GitHub 的 `git/trees/main` 返回的是树对象 SHA，不是 commit SHA。清单将其明确命名为 `tree_sha`。关键源码与对应树中的 Git blob SHA 已核对一致，并为所有本地来源文件保存 SHA-256。

`data_explorer_blog.html` 与相应 `.txt` 的直接请求返回了 DABStep 榜单内容，不是博客正文；这两个文件保留作访问记录，**不能作为文章正文快照使用**。报告中 Data Explorer 的方法依据来自原博客的公开检索内容。`downloads.json` 是早期下载记录，不表示每个响应内容都与标题一致；以 `source_manifest.json` 的状态备注为准。

Google 官方 MLE-STAR 文章的旧代码目录没有出现在本次完整、未截断的 `adk-samples` 仓库树中。本档案记录的是当前入口未确认可用，不意味着该方法从未开源或其他位置不存在实现。
