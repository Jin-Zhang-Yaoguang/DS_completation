- **模型族探针**：RealMLP-TD 0.9442、TabM 0.9447、XGBoost 与 HistGB 未带来稳健增益、稀疏加性模型约 0.94448、单调约束 TE −0.00056、收入作 LightGBM 高基数类别过拟合。类权重 v67 仅有使用旧 TE 谱系的两折筛查，未见稳定收益，不是普遍无效的证明。成对排序 v66 只有启动和 iteration 0 日志，没有可用完成结果，不能称为“已完成且无增益”；更正证据见 `diagnostics/loss_objective_review_20260905_resume/evidence.json`。缺少完成结果本身也不是重开训练的机制依据。

- **融合细节**：分层权重（按收入频次）+0.000002；线性 + embedding 加性模型 0.9444。

## 3. 第二阶段验证文档（供 Codex 实施）

### 3.1 目标与总验收

- 主目标：在不使用排行榜探测的前提下，产出一个独立复算通过的严格 OOF ≥ `0.947000` 模型；同时保留单模、小融合和周期超级融合的完整审计链。
- 每个实验只有在满足本节协议的验收条件时才进入最终集成；未通过的也要落盘记录（目录、`cv_results.json`、一行 `experiments.md`）。
- 结束条件：按 `research_cycle.json` 持续运行单模/小融合与每 20 版本一次的超级融合，直到严格 OOF 达到 `0.947000`、用户停止，或所有仍开放研究分支均触发停止条件。

### 3.2 统一验证协议（所有实验必须遵守）

1. **外层划分**：新实验统一预注册为 40 折 `StratifiedKFold(shuffle=True, random_state=42)`。源码复核表明 v61 实际外层种子为 `104395303`（v59/v60 也各不相同），因此与 v61 只能比较整体 OOF，或在共同 seed42 行桶上做诊断；不得表述为相同训练折的配对实验。凡是“改变外层划分种子”的实验单独说明，只比较整体 OOF 与测试预测秩相关。
2. **目标编码泄漏边界**：外层训练折内用内层 5 折 OOF；每个 inner hold 的类别统计和 smoothing prior 都只能来自对应 inner-train。外层验证折与测试集只用完整 outer-fit 标签统计。任何用到测试集的统计只能是无标签量（频次等）。
3. **融合权重**：交叉拟合（固定 5 折划分种子 42 拟合权重，应用到留出折），非负、归一；报告每折权重与融合 OOF。
4. **研究晋级门槛**：单模或成员 相对基准 OOF ≥ +0.0001 且 ≥ 60% 的折提升；融合 相对最佳成员 OOF ≥ +0.0001 且 5/5 交叉拟合折提升。未达到时如实记录未晋级。当前任务的条件提交另按 `RESUMED_RESEARCH_20260905.md` 与候选预注册判定，用户“超过最好即可提交”的授权覆盖旧的不提交限制；历史禁用产物仍禁用。
5. **产物 schema**：每个目录必须有 `oof_proba.npy`（长度 668,665，按 `train.csv` 行序）、`test_proba.npy`（286,571，按 `test.csv` 行序）、`cv_results.json`（至少含 `model`、`n_folds`、`fold_auc`、`oof_auc`、`base`、`base_oof_auc`、`oof_delta_vs_base`、`params`、`elapsed_seconds`）、`train_log.txt`；生成 `submission.csv` 前做 id 顺序与概率范围校验。
6. **禁止**：排行榜探测式融合；用当日 LB 结果调整权重；把未通过 P2-05 来源审计的公开 OOF 放进任何 strict 集成；重复 2.2 列表中的任何实验。
7. **提交权限**：历史预算为 `0`，已被当前用户的条件提交授权替代。候选完成同口径、完整产物和独立复算验收后可提交一次；提交前刷新线上最佳、当日次数与重复 SHA，并在 `experiments.md` 登记预期开发结果。不得依据 Public 微调候选后重复发送。
