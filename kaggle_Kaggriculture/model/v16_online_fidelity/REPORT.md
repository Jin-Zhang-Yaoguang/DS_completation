# 线上 700 名根因调查与 V17 市场护栏（2026-09-03）

## 背景

本地最强的 V120（对 V76/V20 90.6%）与 V10 规则蒸馏（对 V120 85.5%）在线上仅 ~700 名
（rating 1926 / 55971529，V10 51.3%）。本调查拉取三次提交共 341 局公开 replay 逐局归因。

## 根因链（全部经数据验证）

1. **线上池结构**：341 局对手中 199 份不同动作带，43% 属于 ≥3 局的"家族"（同一份公开
   tape 的复制品）。头部家族的产出结构（草莓 250-266 / 羊毛 138-261 / 单人银行 17.3-19.8 万）
   与我方 V120 同级或更强。本地门控对手 V76/V20 远弱于线上中位对手 —— 门控口径错位是
   "本地 90% / 线上 63%"的第一层原因。
2. **失血点集中**：两个"扰动型"家族（c333c13954 / fba802dce0，合计 16 局 1 胜 15 负）+
   三个高产家族（9bdce54945 4/14、30e869f37d 0/6、dea7027bc9 0/5）。
3. **扰动机制（关键发现）**：扰动型家族的带与 OceanMix 家族逐字相同，仅开局多一手
   `t=0 BUY_PRODUCT WHEAT 53 → t=1 SELL WHEAT 48`（净成本 ~200 金币）。它把 t=1 的小麦价
   从 26 抬到 32，使跟随型 tape 的开局清单总价超预算；引擎按清单顺序结算，排在清单末尾的
   `BUY_ANIMAL SHEEP 2` 被挤掉 → 整季羊毛 181→110、草莓 254→142（雇工调度连锁空转）→
   银行 -25k。扰动家族自己的清单是"先卖回血、动物雇佣在前、种子在后"，天然免疫。
4. **产出崩塌只在对局中出现**：V120 单人在任意商店序列/seed 下产出恒定（草莓 254），
   排除了商店序列失配假设。
5. **零收入卖单**：我方每局 26-35 步卖单收入为 0（对手 2-7 步）；羊毛实现均价 14.6-66.8
   vs 对手 53.7-134（败局），是 tape 卖时点与实际市场脱节的次级损耗（本轮未修）。

## V17 市场护栏（v17_market_guard/）

- **防御**（main.py）：a) 开局两步市场清单按 [动物, 雇佣, 种子, 产品] 重排（贵而关键的先
  成交）；b) 第 1-2 天核对牛羊实持 vs tape 意图，缺则补买（≤4 次，钱 ≥500 时）。
- **进攻**（main_attack.py，RESORT_DAY0=True）：自己打出同款扰动（t0 买 53 / t1 卖 48），
  收割线上海量未设防跟随型 tape；进攻版重排覆盖第 0 天全天（经验最优，8 seed 验证）。
