# 对 V120 胜率 ≥80% 的搜索：结论报告（2026-09-02）

> loop 目标：蒸馏 + CEM 自搜，直到出现对 V120 胜率 ≥80% 的模型。
> **结论：未达成，且在"公开 replay 蒸馏 + 参数搜索"的范式内已证明不可达。**
> 全部数字来自修复后的评测环境（见 `model/eval_m6_fixed/README.md` 的勘误）。

## 1. V120 是什么

V120 = OceanMix 最新一局 tape（episode 104547425，多押 4 只羊的"羊毛赌注"）+ V17/V19 系执行器
（weed 修复、库存截断、v20 需求延后、v76 买单前移、v118 羊毛揭示流动性）。
它对 V76/V20 是 90.6%，比我们的 V5（87.5%）略强；V120 vs V5 直接对抗 56/72（V120 占优）。

## 2. 逐个杠杆的实测（对 V120，64 真实场景 × 双席位，商店逐步揭示）

| 杠杆 | 结果 | 结论 |
| --- | --- | --- |
| 精确镜像（V120 执行器 + V120 tape） | 逐局 margin = 0 | 镜像是平局不动点 |
| 镜像 + 单方面时序偏移（提前 1/2 回合、延后、always 模式；GA 2 代） | 全部为负，最好 4.7%，延后 −113k | V120 反应层把任何偏移反吃；tape 的"同回合先卖后买"资金链禁止延后 |
| 镜像 + PASS 填充（WATER/CARE，零副作用） | margin 恰为 0 | tape 的空闲时刻脚下无可做之事，不存在免费 ε |
| V120 执行器 + 我方 tape（V6） | 与 V5 自带守卫逐场相同 | 执行器不是镜像局的决定因素 |
| 换 tape：OceanMix 家族 23 条唯一续盘 | 最好 = V5 档；失真环境 oracle 53% | 家族内无更强计划 |
| 换 tape：其他五队 ~500 条轨迹粗筛 + 复核 | 最好 tetsuya 103951199：修复环境 23.4%，新 40 seed 32.5% | 单条轨迹不可迁移 |
| **羊毛赌注对冲（V8）**：未见 yarn 则跳过第 7 天起的买羊 | **64/36/28 = 50% W / 28% L / 22% T** | 唯一正向杠杆；把部分必负局变成平/胜 |

## 3. 为什么 80% 在此范式内不可达

- 胜负由**赛季是否出现 YARN_STORE** 决定（有放回抽样，P(≥1) = 66%）：V120 的计划押羊毛，
  yarn 出现即赢；不押的计划（V5）在 yarn=0 时赢。任何提前承诺的计划都被这个 66/34 分布锁死。
- 唯一逃脱方式是**在 yarn 揭示时再决定买羊**——但 tape 里买羊/放羊/喂羊是跨天的动作链
  （PLACE SHEEP 在固定步 258–270），延后购买需要重排后续几十步的单位动作，超出"tape + 守卫"
  的能力，需要一个真正的执行器（这正是 V1/V4 自研执行器失败的地方）。
- 镜像局是平局不动点，V120 的反应层使一切单方面偏移为负。

（yarn 揭示驱动），并用 CEM 搜索改写参数。预估 2–3 天工程；成功上限约 W 60% / T 25%（平局
不可消除），仍难到 80%。
