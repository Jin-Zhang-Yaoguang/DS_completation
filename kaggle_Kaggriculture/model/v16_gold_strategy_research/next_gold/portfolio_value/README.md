**保留 day3 两路线，不扩到 3–5 路线，也不把整条路线决策延迟到 day6。**

真正的下一方向不是继续猜一条 719 步固定路线，而是保留 V17 的 day3 宏观分流，在路线内部加入事件驱动的在线纠偏：每次新店解锁、市场库存跨阈值、对手公开产能变化时，只重算后续边际生产和销售，不推翻已经投入的土地、动物和劳动力。

## 为什么不扩路线

开发集贪心加入的第 3 条为 `tyz123456::99630579`；第 4、5 条为 `Kronki::99628245/99628290`。

| 路线数 | 未见 per-game oracle | 首店可实现路由 | 相对单路线 |
|---:|---:|---:|---:|
| 2 | 88.594% | 81.562% | +0.938pp |
| 3 | 89.766% | 76.562% | -4.063pp |
| 5 | 91.406% | 76.562% | -4.063pp |

路线越多，事后 oracle 越高，但首店无法识别应选哪条路线，日期外推反而显著变差。这是典型的不可观测状态过拟合：增加动作集合，却没有增加足够的因果信息。

在满足以下全部门槛前，不再增加第三路线：

1. 新路线必须在预注册开发集和未见日期上都增加至少 `+2pp` per-game oracle；
2. 低容量因果 router 在未见日期至少回收新增 oracle gap 的 `30%`；
3. 相对 V17 的 score 配对聚类 95% CI 下界大于 `0`；
4. worst-family score 不下降超过 `1pp`，CVaR10 不恶化；
5. 路线必须拥有严格公共前缀或通过完整状态兼容认证。

## 为什么不延迟到 day6

保留默认公共前缀到 step144、再使用前两店选择路线的反事实，相对当前 day3 分流：

- score `-0.625pp`，95% CI `[-1.406,+0.156]pp`
- margin `-330`，95% CI `[-786,+137]`
- 5 改善、1,262 不变、13 恶化；4 个未见谱系中 3 个 score 为负

第二家店没有补偿 day3–day6 错过的专用生产窗口。该反事实的 replay tail 还没有生产级状态兼容认证，因此即使点估计为正也不能直接晋级；当前点估计已经为负。

只有 day6 候选相对 day3 V17 同时满足 score 和 margin 的聚类 95% CI 下界大于 0，并且 worst-family/CVaR 不退化，才允许重启延迟路线研究。

## 第一性原理后的下一实验

剩余约 `7.03pp` 的两路线 win-oracle gap，不应被当作一个分类模型要拟合的标签，因为决定它的大量信息在 day3 尚未发生。正确目标是降低策略对未知未来的敏感性。

下一候选应采用“day3 宏观承诺 + 后续边际 recourse”：

1. step72 仍只用首店选择 `YARN` 或 `DEFAULT` 宏观资产方向；
2. step144/216/... 不切换整条路线，只根据新店、市场库存、剩余成熟周期和对手公开产能，重算未来 72 步的增量种植、动物购买和销售节奏；
3. 土地、动物、劳动力等不可逆投入用 robust/CVaR 目标决定；种子、短周期作物和销售属于可逆控制；
4. 用滚动时域仿真比较“固定尾部”和“同宏观路线 + recourse”，评价必须使用未见日期、未见 seed、双席、谱系等权；
5. 首个晋级门：相对 V17 score `>= +1pp`、聚类 95% CI 下界 `>0`、worst family 不下降、CVaR10 不下降。

这比增加静态路线更接近金牌策略：不预测不可预测的未来，而是在信息到达后以最低沉没成本调整。

## 证据边界

- `results.json` 是 fixed-stream 上界研究，不是 live-policy 或 Kaggle 金牌证明。
- `paired_certification.json` 使用未见日期和 disjoint seed，但只覆盖 4 个历史强代理谱系。
- step120、第二家店均晚于 V17 的 step72 决策，只能作为信息上界；不能计入当前策略的可实现收益。
- day6 分支把 replay tail 接到公共默认前缀，尚未通过生产级状态兼容认证。
