# 下一代金牌策略：第一性原理结论

## 结论

V17 的主要上限不在继续寻找一条更强的固定路线，而在把它改造成**按公开状态持续重规划的双人博弈策略**。

最重要的事实是：V17 在第 72 步看到第一个商店后，就冻结整季路线；但第一个商店只占整季商店需求权重的 **20.45%**，之后仍有 **79.55%** 的随机需求尚未揭示。当前固定路线池的不可实现逐局 oracle 已把得分率从 **83.54%** 提到 **92.03%**，说明路线多样性里仍有 **8.49pp** 的选择上界。真正值得投入的方向，是把这部分 hindsight 信息变成每三天一次的因果决策，而不是围绕 A2 或某一条回放微调。

## 规则推导

1. 市场不是独立定价器，而是双方争夺的公共容量。每个订单槽位按索引交错处理，同槽双方逐单位看到相同的提交前库存；市场处理完才发生城镇消费。源码证据：`sim/sim.hpp:528-577`、`sim/sim.hpp:660-677`。
2. 商店在第 3、6、9、12、15、18、21、24 天解锁；从解锁到终局分别剩余 162、144、126、108、90、72、54、36 次消费，总权重 792。
3. 商店随机且有重复。单商品店每次消费 2 单位，其他店每商品消费 1 单位。完整赛季的外生需求并非小扰动：

| 商品 | 期望城镇消耗 | 随机标准差 | 变异系数 | 极值范围 |
|---|---:|---:|---:|---:|
| WHEAT | 525 | 146.9 | 0.28 | 30–822 |
| CARROT | 327 | 211.1 | 0.65 | 30–1614 |
| TOMATO | 228 | 131.4 | 0.58 | 30–822 |
| STRAWBERRY | 426 | 151.7 | 0.36 | 30–822 |
| MELON | 30 | 0 | 0 | 30–30 |
| EGG | 228 | 131.4 | 0.58 | 30–822 |
| MILK | 327 | 146.9 | 0.45 | 30–822 |
| WOOL | 228 | 200.6 | 0.88 | 30–1614 |
| FERTILIZER | 0 | 0 | — | 0–0 |

4. 对手农场、现金与市场库存公开，只有对手仓库和随身库存隐藏。因此对手未来供给不是不可知噪声：作物年龄、动物种类、可收获量、运输位置和历史出售节奏都可用于建立供给分布。
5. 评分只看最终胜负。策略目标应是 `P(终局现金差 > 0)`，而不是期望金币最大化。领先时减少左尾，落后时主动提高有正胜率的方差，才与比赛目标一致。

## 按 ROI 排序

### 1. 多阶段需求与对手供给联合重规划

**预期收益：+3–8pp；开发成本：中高；优先级：最高。**

每次商店解锁、重大收获和市场库存越过价格曲线拐点时，重算每种商品的剩余市场容量：

`未来库存 = 当前库存 + 我方承诺供给 + 对手供给分布 - 已知城镇需求 - 可购买回收量`

再用 1.32.7 的精确价格曲线计算每个新增生产单位的终局胜率边际，而不是静态基础价格。生产决策同时计入成熟期、动作数、运输、仓容、现金约束和对手对同商品的挤压。

因果触发点：

- 第 72/144/216/288/360/432/504/576 步：商店信息累计由 20.5% 增至 100%；
- 对手新增某类作物或动物、进入集中收获窗口；
- 市场库存跨过 `I0±T` 或价格边际发生显著变化；
- 领先区间跨过安全阈值，需要从增长模式切换为守胜模式。

实现上不应直接拼接不兼容回放后缀。应保留 V17 路线作为 rollout 先验，构建能从任意合法状态继续执行的在线任务调度器，至少每三天滚动规划一次。

上界证据：同一固定路线池、独立测试 seeds 中，商店路由为 83.54%，逐局路线 oracle 为 92.03%；平均 margin 上界增加 5,802，P10 从 -5,470 提到 +1,161，最差家族从 61.56% 提到 69.06%。Oracle 不可直接提交，但证明“正确选生产体系”远比微调单个动作更值钱。

主要风险：任意状态续接失败、把未来商店泄漏进训练、对手供给模型过度自信。下一实验必须使用时间因果特征，按日期和策略谱系留出，并在双方席位上报告家族等权胜率与 CVaR。

### 2. 胜率效用与领先/落后双模式

**预期收益：+1–3pp；开发成本：中；优先级：第二。**

定义对手隐藏库存的上下界，得到终局 margin 分布：

- 若我方终局下界已高于对手上界：停止长周期投资，优先清仓、喂养保全和压低对手主商品的公共价格容量；
- 若区间重叠：最大化胜率，优先低方差、已知需求商品；
- 若我方上界仍落后：切换到高弹性、与对手供给负相关的稀缺商品，接受更高方差。

这会直接改变产品组合和出售时机，而不只是终局补一个 SELL。最重要的触发不是固定天数，而是 `P(win)` 或保守 margin 区间越过阈值，例如 70%/30%。

主要风险：对手私有库存边界过宽，导致模式频繁抖动。下一实验应固定生产规划器，只替换效用函数，比较窄胜局的 W→L 与 L→W，而不是比较平均金币。

### 3. 市场订单 SELL-first 门控

**实测上界：+1.67pp；安全版本预期：+0.3–1pp；开发成本：低；优先级：第三。**

把本方 SELL 保持相对顺序地移到非 SELL 订单之前，是可部署的因果后处理器：它只读取本方当前动作和当前公开状态，不读取对手同时刻动作、未来状态或私有信息。机制上，原本排在 HIRE/BUY_* 后面的 SELL 会让对手先占用同商品的高价库存容量；前移后既可能得到更高报价，也能让后续对手卖出承受更低报价。

精确 1.32.7 cppsim、18 条近期强路线、6 个对手家族、80 个未见 seeds、双席共 17,280 局：

- 得分率 `45.06% → 46.73%`，**+1.67pp**；
- 平均自身金币 `+447`，平均 margin `+689`；
- 278 个 L→W，同时有 109 个 W→L。

因此它是“值得继续”的机制，但**不能无门控直接加入提交**。失败来源包括：WHEAT/FERTILIZER 可被对手 `BUY_PRODUCT` 回收，前移不再单调；改变现金顺序会改变本方购买/雇工是否成交；固定路线可能没有为新增成交资源准备后续动作。

下一实验门：只跨越在当前现金下本来就能成交的 HIRE/BUY_LAND/BUY_SEED；含 BUY_PRODUCT/BUY_ANIMAL 的回合不改；优先限制在对手不能从市场购买的七种商品。随后在 V17 完整策略上做未见日期、未见家族、双席闭环验证，要求每个家族不退化，且 W→L 不增加。`safe_slot_gate.py` 已编码该充分条件，但本轮未把未完成运行当作证据。

### 4. WHEAT 城镇库存做市

**预期收益：0–1pp；开发成本：中；优先级：第四。**

1.32.7 中只有 WHEAT/FERTILIZER 可 `BUY_PRODUCT`。没有城镇需求时，买入再卖出的价格序列完全相消；跨过一次城镇消费后，WHEAT 才有正套利：

`利润(q,D) = Σ P(I-q-D … I-D-1) - Σ P(I-q … I-1)`

其中 `q` 受现金和 100 仓容限制，`D` 是持有期间确定发生的 WHEAT 城镇需求。正确触发点是市场处理在前、城镇消费在后的 `step % 4 == 0`：消费前买入，下一步再出售。

但它会占用仓容、现金和订单槽位，还可能给同回合卖 WHEAT 的对手抬价。已有冻结流 oracle 小幅为正，而闭环延迟实验平均 margin 为负，说明不能仅按理论价差执行。只有当保守利润扣除对手补货、资金机会成本和仓容影子价后仍为正，才允许交易。

### 5. 同商品供给外部性的攻防出售

**预期收益：0.5–2pp；开发成本：高；优先级：第五。**

领先时，提前出售与对手同商品的库存，不仅获得自身收入，还降低对手后续报价；落后时则更应避开对手的集中供给，等待城镇吸收后出售。触发量应来自对手公开农场的未来 `H` 步可收获量与历史运输周期，而不是对手身份标签。

订单槽位的非因果 rival-action oracle 在 17,280 局中只有 +1.58pp，且对 Kronki 为 -0.35pp，说明“猜对手下一张订单”不是主线。更高 ROI 的做法是预测数日供给区间，并让生产与出售联合响应。

## 下一项应做的研究

只推进一个主实验：**Day-3/6/9 滚动重规划器**。

1. 从 V17 的公共前缀开始，建立任意状态可执行的任务调度器；
2. 第 72、144、216 步分别根据累计商店、市场库存和对手公开生产估计，选择未来 6–9 天的生产预算；
3. 用精确 1.32.7 cppsim 在未见 seeds 和未见回放家族上优化家族等权胜率，禁止使用未来商店；
4. 与“仅第 72 步路由”的冻结 V17 做 paired 比较；晋级门为总体至少 +2pp、最差家族不下降、P10/CVaR 改善、无状态兼容失败。

若这个实验不能从 8.49pp oracle 上界中拿回至少 2pp，就说明当前路线库缺少真正互补的可续接专家；此时才应转向从头搜索新的在线生产器，而不是继续扩大固定回放库。
