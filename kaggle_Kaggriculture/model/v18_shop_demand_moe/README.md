# V18 商店需求驱动八专家 Router

## 结构

- 第 72 步只读取已公开的首个商店，选择八个商店专家之一。
- 八个专家共享 V17 的安全执行器和两条第 0–71 步严格一致的完整 Replay 路线。
- `YARN_STORE` 使用 yarn 路线，其余七个专家使用 default 路线；专家差异来自公开商店需求目标，不来自不兼容的生产动作拼接。
- 第 144、216 步用当前已公开的商店列表更新动物/种子需求目标。
- 需求高于所选路线原始商店序列时，只把低频需求商品的一小部分计划卖单跨过城镇消费时点，单个需求单位最多延迟 4 件；高频 `WHEAT` 明确排除，不拼接生产动作、不注入额外种植或动物动作。

## 安全边界

- 复用 V17 的购买可执行上限、单位动作 fail-closed、手数对齐、杂草恢复、库存转移、卖单排序与终局清仓。
- 两条生产路线在路由点前动作逐步完全一致，因此选择时的现金、位置、土地、劳动力和库存状态一致。
- 前五 Replay 的八条原始尾段只作为策略研究证据，不进入候选包。探索评测中直接移植方案相对 V17 下降 46.43 个胜率百分点，已明确淘汰。

## 晋级规则

- 固定种子、每个种子双座位、相同对手谱系，与 V17 逐单元配对。
- 主门：按 seed 聚类 bootstrap 的胜率提升 95% 区间下界大于 0。
- 护栏：每个主要对手谱系的点估计不低于 V17 超过 2 个百分点。
- discovery 通过后才运行不少于 600 个候选对局的 confirmation；否则不晋级、不提交 Kaggle。

## 最终结果

- RC1 discovery：候选 109/0/19，父代 112/0/16，配对胜率 -2.34pp，淘汰原始 WHEAT 延迟和第三条 SMOOTHIE 路线。
- RC2 confirmation：48 个冻结 seed、7 个对手家族、双座位；候选与父代各 672 场，均为 574/0/98，胜率 85.42%。
- 配对胜率提升 0.00pp，seed 聚类 bootstrap 95% 区间 `[0.00, 0.00]`；主门失败。平均自身金币 +68，但平均金币差 -434。
- 最终包抽查 8/8 局与研究策略逐动作、逐美元一致；53,731 个非 PASS 单位动作前置条件全部有效，hands 和 market 长度无异常。
- 结论：八专家结构保留为研究产物，V17 继续作为父代；V18 RC2 不晋级、不提交线上。
