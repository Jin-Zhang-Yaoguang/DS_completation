# v11_annex — "多买"方向的可执行形式：作物替换（负结果归档，2026-09-02）

目标：在 V10 之上找到**对所有城镇都为正**的增量生产，使新模型对 V10/V120/V76/V20 各 ≥75%。
对 V120/V76/V20 V10 已经 ≥85%；难点全在 V10 本身——V10 与其任何"少买"变体在多数城镇是镜像平局，
75% 胜率要求在绝大多数城镇**严格**优于 V10。

## 可行性分析（V10 镜像参考对局）

- tape 全季用满全部 75 块解锁地（无地块空闲 ≥ 8 天）；第 0–10 天现金最低 10–485，第 11 天起 ≥12k；
  shed 在第 12–13、24–28 天顶到 85–100；HIRE 集中在第 0 小时（第 1/3 小时少量）。
- 结论：加地（SE $4000）+ 加人（第 13/14 个临时工每日 144/233）的附属农场 ROI 为负到勉强持平；
  唯一零额外劳动的"多产"是**替换纯小麦轮作地块的作物**（14 块，3–4 天一轮，浇水/收割动作与作物无关）。

## 实验（均为 V10 镜像 vs V10，5 seed）

| 变体 | margin | 结论 |
| --- | --- | --- |
| 小麦→甜瓜 12 块，第 11–13 天 | −6.1k ~ −6.6k | 镜像对手第 10–11 天已倾倒 72 瓜，晚到的 60 瓜卖到 $1 地板（sq 曲线 +190 归零） |
| 小麦→胡萝卜 14 块（有胡萝卜店时） | −7.8k ~ −8.8k；K=4 时 −1.4k | 连续卖出时胡萝卜≈base $35 ≈ 小麦（累积稀缺后 35–45），还多付种子；"$60 的坑"只在积累后卖才存在，而仓容禁止积累 |
| 小麦→草莓 6 块 | +30 ~ −1.6k | 镜像双方各卖 298 > 坑 426，已饱和 |
| 胡萝卜替换 vs V76（非镜像） | 4/5 seed 比 V10 本体差 4–7k | 对非镜像对手同样为负 |

溢出诊断：日终丢弃约 20 件，与镜像相当，不是主因。

## 为什么这一族没有解

V10 的骨架（OceanMix 最新计划）在劳动/地块/仓容预算下已是局部最优；镜像对手把 tape 能产的每种产品
（奶 377×2 vs 坑 327，羊毛 241×2 vs 228/店，草莓 298×2 vs 426，甜瓜 72×2 vs 30+sq 曲线）全部打饱和，
只有蛋（V120 系卖 0 个，坑 228）与胡萝卜（卖 14，坑 327）未饱和——但蛋需要 COOP 与每日 3 个动作/鹅的专属劳动，
胡萝卜的价值只在积累后卖进深坑时才存在。两者都需要重排劳动与仓储，超出 tape 覆盖层的能力。

## 若要继续

需要可重排执行器（把 tape 反编译为任务图、以 tape 排班为默认解、允许插入"养鹅/晚卖胡萝卜"的任务链），
再用 CEM 搜索任务链参数。预估 1–2 周工程；对 V10 达 75% 的概率我判断不超过一半：
增量来源只有蛋/胡萝卜两个小坑（合计约 +3–6k/季），而 V10 的镜像噪声与席位效应量级相近。
