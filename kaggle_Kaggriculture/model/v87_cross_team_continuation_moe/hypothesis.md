# V87：跨团队行为簇整段续航 MoE

## 原创身份

- `strategy_parent=null`。
- V76 只作为冻结强度比较器，不向候选提供默认动作、完整策略体或运行时回退。
- 专家训练证据来自 2026-08-27 已冻结的前五名公开 Replay；必须记录团队、submission、episode 和 seat 来源。
- 候选不得调用任何历史完整 agent，也不得逐回合在多个历史 agent 输出间择优。

## 第一性原理假设

Kaggriculture 的土地、劳动力、动物、种子、库存与出售节奏是长期共同适配的系统。V86 失败表明，把生产、恢复和市场模块逐回合重组会破坏这种共同适配。V87 改为把完整赛季行为看作“option”：Router 只在状态兼容边界选择一次专家，随后整段承诺；安全执行器只处理合法性与有限状态对齐，不重新决定生产组合。

这不是 V17/V21 的小版本扩展。待验证的新杠杆是：

1. 专家来自多个榜首团队的行为簇，而不是同一父代的两条路线；
2. Router 的目标是选择整段 continuation option，而不是切换商品或动作块；
3. 专家必须在新种子上仍有闭环强度，且相互行为距离足够大；
4. 若首店出现前不存在可预测信息，则不伪造“种子指纹”，而要求后续构造显式解决状态对齐。

## 已证伪的子假设

固定 PASS 开局下，step 1/2/4/8/24/48 的公共市场价格与库存向量在 5,000 个合成种子中均只有一个唯一值。用这些特征预测首店的准确率约 12%–13%，不高于八分类随机水平。因此 V87 不使用“开局市场种子指纹 Router”。

## 构造前专家池门

先取当前前五高分槽位各一条中位行为代表局：Crop Dusta、Milan Leonard、Ryo Hasegawa、Subramanya N、lucaskna。每条完整动作流在 16 个全新合成种子、双座位下，分别对战冻结的 V20、V21、V32、V54、V66、V76，共 192 局/路线。

一条路线成为“可用专家”必须同时满足：

- 719 步完整动作流，运行错误为 0；
- 六对手等权得分率不低于 50%；
- 对 V76 得分率不低于 30%；
- 与另外至少两条可用路线的全局动作不一致率不低于 15%；
- 生产/市场动作画像不是同一向量的近重复。

只有至少三条路线满足门槛，才进入独立候选构造。否则决策为 `REJECT_PRECONSTRUCTION_WEAK_OR_COLLAPSED_EXPERT_POOL`，不消耗官方 Replay Confirmation。

## 若专家池通过，下一阶段的必要构造

- 训练一个只使用公开状态的浅树 Router；Router 不得看到 seed、对手私有库存或 Replay 身份。
- 用候选自有的状态对齐桥接器，把统一前 72 步产生的真实状态映射到所选 continuation 的状态契约；若桥接不能在固定期限内恢复资金、人数、关键资产与位置契约，则回退到候选自有的独立默认专家，而不是 V76。
- 主消融是“同一安全执行器 + 单一最强跨队专家”，用于检验 Router 是否真的创造增益。
- 构造完成后重新打包为仅含一个 `main.py` 的 Kaggle 可提交归档，再进入 Development。

## 淘汰条件

- 专家池少于三条；
- 专家仅在来源 seed 或来源对手下有效；
- 行为簇实质坍缩为同一路线；
- 状态对齐需要调用历史完整 agent；
- Router 相对单专家消融没有正向配对增益。
