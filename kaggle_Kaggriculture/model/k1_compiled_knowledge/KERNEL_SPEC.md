## 内核规则（按实测翻译）

- **M1 同格清空**：单位所在格有可做任务时继续做完，不离开。
- **M2 格内次序**：动物格 FEED → COLLECT_FERTILIZER → HARVEST → CARE；
  作物格 HARVEST → WATER → FERTILIZE。
- **M3 纯就近派活**：非生存任务不分优先级桶，全局按（距离, 次序）贪心匹配；
  目标按「格」占用（一格一人），避免多人奔同一格。
- **M4 生存任务先行**：濒死喂养/濒枯浇水仍先于就近匹配（保零饿死红线）。
- **M5 小批高频领麦**：途经仓库且持麦 < 2 时领 3 个；不做大批补给。
- **M6 肥料不进仓**：施肥只由随身携带者执行，肥料来自收肥动作；不从仓库领肥。

## 扩面积为什么亏（area_cost_diag.py，2026-09-16；ga4 最优，y68g + v2 × 4 seed × 双席位 = 16 局/配置）

拆解（相对基准，按对手分开看）：
1. **劳力不是约束**：工作次数 2041-2138 基本不变，雇工 253 次不变，现金低于 200 的天数变化 ≤ 3 天。
2. **小麦目标没兑现成面积**：「小麦 +12」作物格·天 -1~-36（不增反降），小麦卖量 -15~+16——被每日种植限速与现金/种子挡住，own 的变化（vs y68g -10.6k）来自奶 -4.7k、毛 -2.8k 等**与小麦无关的品类**。
3. **草莓扩种被自身价格弹性吃掉**：「草莓 +10」作物格·天 +110~+118（+15%），种子 +1.1~+2.9k，草莓卖量只 +8~+12，**草莓均价 146→130（vs v2 153→130）**，草莓收入 -2.7k~-7.5k；枯死/未收草莓 +4~+5 格。边际收入 < 种子成本。
4. 番茄同理：面积动作让番茄价 -13~-28、收入 -0.8k~-3.0k。
5. **商店序列内生放大噪声**：任何面积改动都会改变双方行为 → 商店解锁序列 → 奶/毛价格大幅漂移（例：vs y68g 毛价 185→120，毛收入 -8.5k；vs v2 毛价 132→177，毛收入 +5.2k）。单项品类 ±5k~±10k 的摆动主要是这一混沌效应，不是机制。

结论：扩面积亏的直接机制是 **自身供给压价（草莓/番茄的价格弹性）+ 种子成本**，外加小麦扩种根本没兑现；叠加商店序列内生带来的大方差。
对照 Majkel（value_distill）：草莓卖 204 件、均价 165；K1 卖 130 件、均价 134——Majkel 卖得更多价格反而更高，差距在**卖出节奏与需求匹配**（何时卖、卖多少、跟哪些商店的消耗走），不在面积。
下一步：量化各产品的价格冲击与恢复（MARKET_PARAMS + 商店消耗），推出「每块地/每头动物的边际收入」与卖出节奏，作为经济计划器的目标函数。
