# V18 planner-scheduler：浅规则 + 贪心调度 + 离线搜参 研究方案

日期：2026-09-03。前置结论（v16 调查 + v11 蒸馏研究 + v15 执行器实验）：
金牌级选手 = 浅规则树（分支砍在信息揭示点）+ 贪心任务调度器（PASS ~5%）+ 离线仿真调参。
本方案沿此路线构建原生调度器 agent，替代 tape 直译底盘。

## 0. 架构：三层分离

```
计划层 plan genome（可解释常数向量）
  ├─ 开局骨架：雇佣节奏 / 动物基数 / 甜瓜12 / 象限解锁时刻 / 小麦轮作密度
  ├─ 条件规则（继承 V10 RULEBOOK）：羊+=f(yarn首现日)、牛+=f(奶店数)、莓=f(莓店数)、
  │   开局变体=f(对手开局签名，已知仅 5-7 种)
  └─ 卖出参数：批量 / tick 对齐 / 终局清仓时刻
调度层 executor（V15 闭环调度器为底座）
  ├─ 任务生成器：每小时枚举待办（收获/浇水/喂食/照料/收肥/播种/除草补种）
  │   ※ 空地=杂草温床（杂草只在空地生成），"空地立即补种"是硬任务
  ├─ 优先级函数：参数化权重（~10-20 维连续参数）
  └─ 贪心分派：工人-任务最近匹配，路径成本感知；不做在线树搜索（1s 时限内不必要）
市场层 guard（V17 直接继承）
  ├─ 清单重排 + 资产守卫（防开局扰动）
  ├─ 开局扰动开关（进攻）
  └─ 现金护栏：种子提前 1 天备货、现金 buffer，最小化对市场价格的耦合
```

## 1. 初始态（M0）

**不随机初始化——直接站在 meta 肩膀上：**
- 计划层常数从 V120 路线 + CornHub 带（fam_B，单人 19.8 万）反推；
- 条件规则从 V10 RULEBOOK 原样继承（已线上验证 85.5% vs V120）；
- 调度层从 `v15_closed_loop` 起步（动物侧已持平：肥料 339/378、羊毛 175/196；
  **田间侧落后 15-25% 是已知卡点，M0 主攻**：小麦 351/567、草莓 103/260）。

**M0 验收（只看物理产出，不进对战）**：kagsim 单人（对手 PASS）8 seed：
银行 ≥19 万（对标 CornHub 19.8 万 / OceanMix 19.7 万）、PASS ≤8%、
草莓 ≥245、羊毛 ≥175、空地日均 ≤2。

## 2. 搜索怎么迭代（M1-M3）

三层搜索、全部离线仿真（kagsim 0.3s/局，并行一代 <1 分钟）：

| 层 | 空间 | 算法 | 目标函数 | 节奏 |
| --- | --- | --- | --- | --- |
| 内层 | 调度权重（连续 10-20 维） | CEM / 坐标下降 | 单人银行（固定 8 seed 均值） | 自动，每代 50-100 局 |
| 中层 | 计划常数（离散小空间） | 逐参数网格 + **同 seed 同商店双席位配对打母体**，只收净增益 ≥阈值的变异 | 配对净胜差 | 自动 |
| 外层 | 条件规则 / 开局变体（结构） | 假设驱动：败局 exact_rev 归因 → 提失败机制 → 写一条规则 → 中层验证 | G1/G2 门控 | 每天 1-2 个假设 |

外层规则来源（优先级序）：
1. **"多买"方向**：yarn 早现加羊、奶店多加牛——V10 只能做"少买"，调度器解锁"多买"（把
   "第 d 天追加 k 只羊"落成动作链正是本方案的原点）；
2. **家族最优响应**：线上对手 43% 是确定性家族 tape，对确定性对手可搜精确反制；
3. 卖时点与市场联动（修零收入卖单 26-35 步/局、败局羊毛贱卖 15 vs 54 的损耗）。

训练对手池：7 家族 tape + V120 + V10 + 自身上一代（防过拟合单一对手）。

## 3. 评分与门控（从便宜到贵逐级放行）

- **G0 物理门**：M0 验收标准（见上）。不过 G0 不进对战。
- **G1 家族门（线上代理，权重最高）**：7 家族 × 8 seed × 双席位：
  跟随 5 家族各 ≥75%、扰动 B ≥60%、C ≥40%；按线上家族局数占比加权综合 ≥70%。
- **G2 M6 门**：64 场景×双席位：vs V120 ≥55%、vs V76/V20 ≥85%、vs V17a ≥50%（不输现任）。
- **G3 上线门**：官方引擎 DONE/DONE、单文件包（入口=最后可调用）、与模块版逐分 MATCH、
  remainingOverageTime 无下降（1s 时限余量）。
- **线上判定**：≥80 公开局后报 胜率 + Wilson 下界 + 家族分解（对手聚类工具复盘），
  与 V17a 同期对照；publicScore 不做单点判断（recent15 教训）。
- 纪律：每个挑战者一行 experiments.md（参数、G0-G2、结论）；固定 seed 可复现。

## 4. 效果不好怎么持续迭代（预设失败模式 → 对策）

| 失败模式 | 诊断工具 | 对策 |
| --- | --- | --- |
| G0 不过（田间密度上不去） | exact_rev 对 CornHub 带逐日逐块归因：浇水延迟/收获延迟/播种空窗哪一环 | 把 CornHub 带的田间动作当"任务完成时刻表"做差分；贪心不够则升级为小时内 2-opt 微排序（仍不做全局搜索） |
| G1 不过（对战中产出掉） | trace_break 找第一个分叉步 | 资金/市场解耦：种子提前备货、现金 buffer（V120 被扰动打崩的教训） |
| G2 vs V120 不过 | 同 seed 同商店逐日银行差归因 | 定位系统性落后时段，回外层出假设 |
| 本地全绿、线上不好 | 重拉 replay 聚类 | meta 漂移：每周刷新家族门对手池（新家族/扰动型占比变化） |
| 4 个外层迭代（约一周）G1 无改善 | — | **退出条件**：回退为混合架构——V17a tape 管战略、调度器只接管田间层（补种/除草/浇水），保底吃掉空地-杂草损耗 |

**止损与 A/B**：V17a 始终保留一个线上 slot 不动；挑战者只用另一个 slot 轮换
（复刻 Crop Dusta 的多版本并跑）。

## 里程碑

- M0 田间密度追平（G0 全绿）——主攻，预计占一半工作量
- M1 内层+中层搜索管线自动化
- M2 条件规则接入（"多买"）+ G1/G2 全绿
- M3 打包上线 + 线上复盘闭环（周更家族门）
