# 现场翻译器：离线证据分析（2026-09-06 凌晨,先于线上数据）

## 翻译器的假想价值 vs 本游戏的实际机制

Crop"每局路线不重复"的推测机制 = 固定计划 + 现场翻译器。但把它搬到我们身上前,
先厘清本游戏里"死走位"的真实来源:

**农场各自独立,对手不能踩我们的地。** 对手影响我们的唯一渠道是市场:
1. 开局抢单/抬价 → 我方动物/种子没买成 → 剧本后续对"不存在资源"的操作级联落空
   （买羊失败则后面 700 步喂羊/剪毛/卖毛全是死动作）;
2. 中盘砸价 → 卖出回款低 → 某步买肥失败 → 肥效期操作打折;
3. 杂草只长在自己没浇水的空地,与对手无关——纯 tape 在自己农场里不存在"被堵路"。

所以本游戏的翻译器真正对应的问题是**级联失效修复**（资源偏差时把死动作重定向到
实际存在的资源）,而不是 Crop 语境下的路线规划。动物侧的级联失效已由 V17 护栏修复
（补买后剧本的喂/剪动作自动作用于补回的动物）。

即:V41 输掉的每一局,剧本 720 步都完整执行了,产出一分不少;输在对手的产出结构
更契合当局市场（羊毛倾销压价/结构差距 5-10k）。**没有一场败局源于死走位或级联失效。**

## 结论（证据门槛判定）

1. 对 V41 而言,翻译器的离线预期收益 ≈ 0——它修复的问题在 V41 的败局里不存在。
2. 真正的差距是「产出结构 vs 当局市场」的错配,这属于**带选择/带生成**问题
   （开发机侧调度器的职责）,不是执行层问题。
3. 待 14:00 线上复盘补充线上败局证据:若线上出现本地未见的失效模式（如开局被抢后
   护栏补买不及时）,再评估针对性修复;否则翻译器降级为低优先研究,资源投向
   微变体轮换（防识别,已在做）与每日带换代（反制 meta 演化）。

红线不变:任何执行层改动只翻译不决策,产出指纹必须与 V41 全同,矩阵不得低于 82.8%。

## 补充（2026-09-06 上午）：意图分析改写了翻译器的正确方向

fam_F 剧本动作分布（720 步 × 全体单位）：走路 45.3%（四方向 3286 步）、浇水 15.4%、
收获 6.4%、照料/施肥/喂食等各 5% 上下、PASS 8%。

关键推理链：
1. 农场各自独立 → 走位层没有任何外部干扰 → "现场寻路"的结果与剧本走位完全相同
   → **走位翻译器在本游戏里没有价值**（这与 Crop 语境不同——它那 45% 走路的
   "每局不同"更可能来自提交端变体或市场层反应，而非局内寻路）。
2. 对手影响我们的唯一通道是市场 → 本游戏里有意义的"翻译器"=市场层的局面反应。
3. 而我们已有的四层浅规则（护栏/LEAD/fill/MM）恰好全部作用于市场层与执行缝隙，
   且每加一层都有实测增益（择时 12/12、LEAD 镜像 4/8→8/8）——
   **我们其实已经拥有本游戏里"翻译器"的正确形态，差的是深度而非方向**。

下一层深化候选（16:15 复盘后决策）：把剧本固定卖单升级为「配额制」——卖什么/卖多少
