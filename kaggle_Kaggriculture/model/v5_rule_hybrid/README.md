# v5_rule_hybrid

V4 四层冠军路线的 V5 线上候选版。R1–R3 保持不变；R4 在检测到陌生公开农场结构时回退到 V1，而不是 V2。

## 四层结构

- `R1`：替换冠军第 72–87 步固定开局。
- `R2`：采用冠军默认整季路线。
- `R3`：根据 `YARN_STORE` 出现时机选择早、中、晚羊毛路线。
- `R4`：陌生结构触发后使用 V1 的完整执行器和路线选择，避免冠军路线过拟合。

R4 的 V1 执行器从第 0 步并行预热内部状态；因此在第 72 步切换时不会把 V1 当成新局启动，也不会丢失喂养、市场和终局清仓状态。
