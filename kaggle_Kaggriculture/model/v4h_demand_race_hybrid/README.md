# v4h_demand_race_hybrid — V4 市场层 × 强生产底盘（DESIGN §8 fallback）

底盘：`model/v1_adaptive_market`（Tetsutani 公开双路线复刻，与 V76/V20 不同源）。
嫁接层只动 market 订单列表，不碰 farmer/hands：

1. **race-reorder**：V4 的 MarketLedger 反解对手卖出流水 + 从对手公开 tiles 预报其
   未来 30 步供给；底盘本回合已计划卖出、且对手同产品供给逼近时，把该卖单移到
   列表最前（同回合更早成交）。不增删任何订单——插入新卖单的版本实测 −2.7k
   （打乱底盘手调时序），纯重排版本无害。
2. **终局保险**：step ≥ 712 时补挂底盘漏掉的清仓单。
