# V88：参考轨迹—状态管道 Hierarchical MoE

- `strategy_parent=null`；V76 只作冻结强度比较器。

- 模型代码只包含候选自有 Router、四类专家与安全执行器。

## 第一性原理假设

V87 证明单条 lucaskna 轨迹在未见合成种子上对六模型面板得分率 67.71%，对 V76 为 65.63%；但其余跨队轨迹不够强，不能组成跨队专家池。真正的机会不在“多路线投票”，而在把强轨迹从开环母带升级成闭环混合控制器。

参考 Replay 在每一步定义一个状态管道：人数、土地、位置、种子、棚库存和现金。Router 比较当前状态与该管道，并在四个 option 间选择：

1. `trajectory`：当前动作合法且关键状态未失配，保持完整轨迹；
2. `spatial_rejoin`：位置、杂草或设施前提失配时，局部移动/清障后回归轨迹；
3. `inventory_rejoin`：PICKUP/PLACE/FEED/PLANT 的库存前提失配时，回棚补货或补种；
4. `capital_rejoin`：土地、劳动力或固定采购因现金/顺序落后时，以可支付数量恢复目标。

专家不是永久切换的第二套完整策略，而是有明确终止条件的恢复 option；恢复后立即回到轨迹。这样保留长期共同适配，同时把随机杂草、市场竞争和部分成交造成的状态漂移闭环化。

## 主消融与晋级条件

主消融是相同参考轨迹的纯母带执行，仅做 hand 数量与 market 长度格式对齐，不启用任何恢复专家。构造前合成门使用 V20、V21、V32、V54、V66、V76，16 个全新 seed、双座位：

- full 与 ablation 均 719 calls、零运行错误、零 action schema 违规；
- 至少三类专家各在 8 局以上真实触发；
- full 相对 ablation 配对得分增益大于 0，正翻转多于负翻转；
- full 对 V76 得分率不低于 50%；
- full 六对手等权得分率不低于 60%。

若通过，才进入官方 Replay Development；否则整条 L 谱系淘汰，不围绕单阈值打补丁。
