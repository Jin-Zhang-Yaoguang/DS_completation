# V92：事件期权—资源 Petri 网 Hierarchical MoE

## 原创身份

- `strategy_parent=null`；V76 仅作冻结强度比较器。
- 单条公开强 Replay 只在构建期被编译为“任务、前置资源、参考位置和市场承诺”，提交包不调用任何历史 agent。
- 与 V88 的状态管道不同：V92 不比较当前状态与完整参考状态，也不以“回到轨迹”为目标；Router 根据任务前置条件是否满足、延期任务是否可完成、资源预算是否可行来切换事件期权。

## 主假设

固定时钟会在一次任务因天气、资源或位置失配失败后永久丢失该生产环节；把失败任务变为有期限的 Petri token，并仅在前置条件重新成立时完成，可在不绑定父代动作的情况下恢复完整生产周期并改善胜负。

## Router 与专家

1. `scheduled_task`：执行当前时钟任务；
2. `deferred_task`：当前任务为 PASS/非法时，完成已重新满足前置条件的延期任务；
3. `prerequisite_task`：通过除草、前往仓库、补取原料或回到参考工作位来创造任务 token；
4. `market_budget`：以当前现金、仓库和当回合单位动作投影约束市场承诺；
5. `safe_idle`：无法证明可执行时 fail closed。

## 消融与构造前门

主消融关闭事件 token、前置任务和资源预算 Router，直接按同一编译任务图的固定时钟执行。预构造使用 16 个全新 synthetic seed、6 个冻结对手、双座位、full/ablation/V76 共 576 局；要求 full 相对消融 MCU > 0 且正翻转多于负翻转，至少 8 局完成延期任务，面板得分率不低于 60%，直接对 V76 不低于 50%，灾难率相对 V76 不恶化超过 1pp，零运行与 schema 错误。未通过即整条谱系淘汰，不调 token TTL 或阈值重试。
