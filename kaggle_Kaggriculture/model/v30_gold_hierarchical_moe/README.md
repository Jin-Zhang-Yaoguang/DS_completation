# V30 Offline-Gold Hierarchical MoE RC1

V30 冻结 V21 的已验证策略：首商店需求 Router 先选择开局路线；`YARN_STORE` 保留 YARN 专家，其余路线在 step 216 切换到 `lucaskna::100485613` 生产专家；所有专家共用状态安全执行器，并由商品级 `demand_delay_25` 卖出控制器约束供给节奏。它是规则/浅层树式 Hierarchical MoE，不依赖对手身份、未来信息或在线模型文件，提交包只有一个自包含 `main.py`。
