# V29 Champion Selection

V29 在 12 个本地模型、64 个全新冻结 seed、双座位下直接比较 V19、V20、V21、V27，每个模式 1,536 场。V21 相对 V19 为 `+14.06pp`，95% CI `[+11.72,+16.67]pp`，翻转 `271/1265/0`；相对 V20 为 `+9.57pp`，CI `[+7.03,+12.37]pp`，`147/1389/0`，两组逐模型护栏均通过。V27 相对 V21 胜率完全相同（`0/1536/0`），仅平均金币 `+3.74`，因此按统计同档选择更简单模型，冻结 V21 进入 V30。

金牌候选总结：V29 证明 V21 的收益不是单次开发集偶然，也不是仅来自 V20 出售控制器。它在 12 个异构模型族上同时显著击败 V19 和 V20，两个比较均无负向胜负翻转，CI 下界分别高于 11.7pp 和 7.0pp；同时淘汰了不显著的 Smoothie 微专家，保留“首店 YARN 专家 / 非 YARN step-216 lucaskna 专家 / 状态安全执行器 / 25% 需求延迟出售”的最小 Hierarchical MoE。该包达到离线金牌候选级，但仍需 V30 独立确认。
