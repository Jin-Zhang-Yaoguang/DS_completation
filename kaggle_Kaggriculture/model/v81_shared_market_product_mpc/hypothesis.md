# V81 假设：共享市场—商品级 MPC Hierarchical MoE

## 第一性原理

同回合市场订单按槽位与对手同步执行，商品价格又由双方共享库存逐单位更新。因此，多商品 SELL 的相对顺序不是单机排序问题，而是一个有限时域、双方耦合的序贯决策问题。

## 单一因果杠杆

在公开结构与冻结路线足够相似的 clone-like 局面，Router 把 V76 的父市场序列当作对手下一队列预测。对每个连续 SELL 块，比较父序、循环移位、逆序、冲击降序和冲击升序专家；使用官方 1.32.7 的逐单位价格及共享库存提交语义，计算候选净现金流减预测对手净现金流，只采用严格改善的专家。

## 与既有谱系的边界

V66 只判断局部相邻 BUY/SELL 交换，V32 在跨 step 的出售时点抢跑；V81 对同回合完整商品序列做反事实规划。V81 不改变各商品数量、不跨固定订单边界，并保留 V76 的生产、安全执行和终局物流。

## 可证伪预测

- 多商品 SELL 块覆盖面应广，候选相对 V76 必须产生有效动作变化。
- 若 clone 队列是假设可用，精确反事实排序应提高 PanelScore，且逐对手退化不超过 3pp。
- 若不同谱系对手的市场队列偏离父序预测，局部 MPC 会过拟合 clone 对局并被固定面板否决。
