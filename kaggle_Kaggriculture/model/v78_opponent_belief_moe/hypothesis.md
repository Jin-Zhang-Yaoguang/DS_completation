# V78 假设：公开对手供给信念驱动的商品抢跑专家

- 批次：`hier-moe-originality-5-20260829`；谱系槽位 B。
- 共同根父代：V76。
- 原创性预判：`NEW_LINEAGE`；最近历史机制 V32 只使用 clone distance，V78 预测具体商品供给方向及置信度。
- 一句话假设：用对手公开作物、动物、成熟度和已解锁商店形成商品级供给信念，在高置信时选择对应商品的同回合抢跑专家，可以降低对手插单造成的价格冲击。

## 因果链

公开农场资产 → 浅树商品供给分数与置信度 → `fallback / product_front_run` 专家路由 → 仅在连续 SELL 槽内把预测商品前移 → 保持买卖量和固定支出顺序不变，同时更早占用该商品市场价格 → 胜负翻转。

## 状态与安全契约

- 每个新日仅用公开状态更新一次信念；置信不足立即回退 V76。
- 市场专家只在连续 SELL 区间内排列不同商品，不跨 BUY、HIRE、BUY_LAND、BUY_SEED 或 BUY_ANIMAL。
- 不改变商品数量、单位动作、生产路线或 V76 fail-closed 安全执行器。
- 对手私有 shed、携带库存、环境 seed 和同回合未公开动作不可见且不使用。
