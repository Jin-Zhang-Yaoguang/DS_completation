# V12B-v2 设计与验收报告

## 决策

保留 V8 作为完整父专家，仅将 B-v1 的市场冲击暂缓 proposal 变成“落后/持平时才
允许”的风险动作。公开银行严格领先时，完整保护 V8 卖单。该机制与 A 的结构分支、
终局安全机制异质，优化目标从平均利润改为胜负翻转。

## 因果诊断

严格相同 `opponent/date/episode/seed/seat` 的 B-v1/V8 配对显示：

- 252 对中，159 对完全不触发且逐局等价；93 对至少触发一次。
- B-v1 得分率相对 V8 为 -1.1905pp，平均金币差却为 +16.63。
- 4 个 `W→L` 全来自同一 source，均为 MILK、step 600、触发前公开钱差 +51。
- 2 个 `T→W` 全来自另一 source，均为 MILK、step 544、触发前公开钱差 0。
- 没有 `L→W`。因此不继续机械调整价格、库存或 held 数量阈值。

## 最强反例与晋级条件

当前两个 `T→W` 只是一个独立 source 的双席位，不是两个独立市场状态；没有任何
`L→W`。公开银行落后可能只是路线投资造成的暂时状态，父策略最终仍可能获胜，届时
V2 仍可能错误放行暂缓并产生新的 `W→L`。此外，产品覆盖几乎全部来自 MILK，不能
外推到 EGG/WOOL。

因此本报告结论是“修复已暴露失败并可进入未见验证”，不是“效果已经泛化”。进入
formal 的最低条件仍应包括：新面板 `W→L=0`、至少一个独立 `T/L→W`、总体和每类
对手得分率不降；任一失败就退回 V8，不依据平均金币差晋级。
