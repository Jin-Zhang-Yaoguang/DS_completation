# R9 逐日资金前缀提案（待根审查，未实现）

2026-09-05。父候选为冻结 R8 `b7080c1181fb672ecc4f0bf96ad580cef5a0f80ed5d39d32908610c02423e693`。本文不修改源、不调用候选、不运行引擎或新比赛。根已告知 R8 新 36 局完整性通过、强度护栏失败；本提案只定义下一项可证伪研究。

## 主假设与已知事实

**主假设：将当前现金全额预留所有未来支出，改成有严格时间顺序的预测现金前缀约束，可在相同净终值选择、成熟日历、劳动、土地与执行规则下，增加前 10 日真实生产销售。** 不把期末预计利润当作立即现金，也不承诺未来收入一定兑现。

R8 已打开首场的直接证据：day 1 开盘现金 893，全期饲料现金预留 831、雇工预留 57，仅余 5；day 3 为现金 833、预留 936，其中饲料 883，模型短缺 103。两天实际自有麦均为 4、当天模型喂料只需 1；当天真实买麦分别花 28、29。这确认新增许可收缩主要来自**全期未来购粮预留**，不是当天真实欠费。day 1–6 仍有空位，不能套用 R7 地块已满的解释。R8 首场前十日非麦真实销售为 1,485，首笔仅 day 4 的 1 肥料 100；这不证明放松约束会改善整局现金。证据见同目录 `cash_constraint.json`，候选调用与引擎重放均为 0。

## 唯一变更及不变项

只更换 `economic_plan` 的资金可行性账本，并增加纯辅助函数/诊断字段；必要时给现有 `feed_ledger` 的相同计算额外返回逐日现金额。`net_cash_model`、`score=net/labor`、`selection_score=net` 的含义不变；净值中的饲料机会成本、成熟日历、劳动、净值排序、每帧一动物、先建后买、扩地门、合约/供料/确认/市场动作规则均保持。扩地若沿用 `cash > land_cost + 600`，只将 cash 明确替换为**经过所有前缀校验可在当前追加的现金额度**，仍保留 600 和当前真实现金门。

本轮不是投资组合优化，不改仓容模型、不引入收入折扣参数、不持久化新增应收账。

## 信用与支出合约

| 项目 | 本轮口径 |
|---|---|
| 信用资产集合 | 每帧从当前 `obs` 冻结己方实际在田动物/作物名单；资格不能由本帧许可反向创造 |
| 可贷商品 | 仅该名单日历中的非 WHEAT、非 FERTILIZER 产品；不从初始仓库、买入商品、背包库存、种子或未落地动物贷入 |
| 新许可/在途资产 | 全部逐日成本、劳动与拟供给照常进入共享模型；**其预测收入不进入信用**，直到后续观测已经在田 |
| 信用时点 | 模型采收日 d 的收入，最早在 d+1 计入；不会直接把 `calendar.goods[d]` 当成 d 日可花现金 |
| 固定支出 | 已付动物/种子不重复扣成本；旧合约尚欠固定款、新许可固定款、扩地款按当前日预留。先建项目即使尚未真买，仍预留其固定款，保留父策略的保守口径 |
| 喂料 | 现有自有麦先按日期分配，只把需外购部分及父策略现有周转缓冲记现金；自有麦机会成本继续进入净值，不同时虚构卖麦信用 |
| 雇工 | 原 `labor_schedule.cash_by_day` 原值、原日期；当前订单槽与 h7 边界不变 |
| 终局 | d29 产出对应 d30 信用，直接剔除；最后实际决策是 step 718/day29 h22，不假设 h23 还能卖或雇工 |

**日内顺序的最小保守实现：** 每个未来日先检查并扣除该日全部模型支出，再加入当天到期信用；两个检查点均记录，负数不得 clamp 成 0。这样 d+1 的预计销售不能给同日 h0 雇工融资。它也保守地不让这笔收入支付 d+1 稍晚才发生的支出；若要允许，必须另做逐时付款日历，超出本轮。当前日只使用已经观察到的现金，不能补记任何过去预计但尚未成交的收入。

设当前已观察现金为 C，E[d] 为存量、在途、全部已许可项目和待测项目的当日应付现金，R[d] 为符合上表条件、在 d 日到期的信用：

```
B = C
对当前日至 day29 的每一天 d：
    B_before_credit[d] = B - E[d]
    若 B_before_credit[d] < 0：拒绝新增融资，记录首个赤字日与金额
    B = B_before_credit[d] + R[d]  # 当前日 R 固定为 0
```

此外，当前帧新增 BUY/HIRE/物料/土地意图总额仍必须能由**当前观察现金扣除本帧已承诺支出**覆盖；本帧 SELL 意图和任何未来信用都不能增加这个上限。存量既有赤字不能因“没有新项目”而抹去；保留已有照护与已购种子的使用路径，但不得把零现金使用旧种子宣称为已全额融资。

## 重价与隔离

给待测项目做假设供给时，必须在临时共享市场副本上加上其日历，再重算**整个已许可集合的所有现金前缀**。信用来源名单保持为本帧原在田集合，新项目只能影响这些旧资产的价格，不能增加其信用数量。拒绝待测项目须回滚临时账本，不能污染下一报价。

建议信用沿用既有 `dated_market_model` 在**信用日 d+1** 的供给与逐单位价格，并为同一商品同一信用批次统一结算一次。该报价已包含 d 日拟产量；不能沿用 d 日成交前高价，也不能把已经加入模型的同批产量再次加库存。新项目造成旧资产信用下降后，需要重查此前已准入项目；不得保留旧高信用。在不改变既有价模的范围内，待测项目也不得提高既有信用上限（与加入前逐日信用取较小值，属于供给重价的单调约束，不是调参折扣）。

仅在田资产的边界意味着产品采收后搬运/待卖的几帧内，其信用会暂时消失；本轮明确接受此保守断档，不暗中增加持久应收账。没有合格收入时，所有支出非负，逐前缀检查应退化为 R8 的全期现金预留。

## 实现前必须通过的微测

1. **早赤字不能被晚收入覆盖：** C=50，d1 支出60、d2 信用100必须拒绝；把信用提前到允许的上一检查点才可改变结论。金额为人工控制，不作收益证据。
2. **日内顺序：** d1 h0 雇工前现金不足、d1 才授信，应拒绝；当前 observed cash=0 时，不得借同帧 SELL 或晚期收入 BUY。
3. **资格隔离：** 同一预测产量，在田资产可贷；未放动物、库存种子、新许可、WHEAT、FERTILIZER 均不可贷。加入新项目不能获得自证收入。
4. **日期终点：** d28 采收最早 d29 授信且不能支付 d29 授信前费用；d29 采收信用剔除；没有 h23 动作假设。
5. **物量/成本不重记：** 自有麦减少现金购买额，不能减少机会成本或同时变卖信用；已付固定款不重扣；现有周转缓冲与全部未来雇工现金不遗漏。
6. **供给重价与回滚：** 新同品产量压价时旧资产信用必须下降；原本可行的前缀可因此拒绝；拒绝后下一个相同报价得到相同结果。信用批次不能二次计量或二次加供给。
7. **同源控制：** 无合格收入时账本与 R8 现金门同结论；保留 `full_reserve` 消融模式，短真实观测动作等价 R8；AST 验证禁止变更的函数相同。

日历可能高估及时照护、路线与仓容，未来需求也可能变化；上述微测只验证账本自洽。需每帧输出原始 observed cash、资格数量、逐日 E/R、首个/最小前缀、当前可花现金、拒绝原因和真实意图，禁止把 forecast 记成已成交。实现复杂度中等：信用名单/日历每帧固定一次，每个报价遍历至多 30 日；不需要新搜索或训练，但整组供给重价及回滚必须有直接控制。

赞同根建议复用已冻结 v3 的**真实 days0–9 自生产非麦销售现金**：分别对 PASS、V120 汇总各 6 局，R9 总额至少 R8 的 1.2 倍；每席的 3 局合计不下降。R8 基数为 0 或来源为 PENDING 时不能自动通过。这是交易来源验证后的现金，不是预测信用额；它允许真实肥料销售，虽本轮不授信肥料，两者语义不同。

伴随报告真实早期种子/动物/土地/雇工/供料支出、实际部署与产出、照护失败、库存/溢出/终局余值、预测收入兑现误差；R0+R8 双重整局强度护栏不放松。若仅增加资本部署却没有增加早期真实销售，主假设失败。即使主指标通过，完整强度护栏失败仍退役。阈值、每席聚合口径与新种子必须由根在运行前锁定。

## 待根裁定的最重要两点

1. 是否采用“未来日全部费用先扣、再授信”的最小保守顺序；它满足不借 h0 未成交收入，但比逐时现金模型更严格。
