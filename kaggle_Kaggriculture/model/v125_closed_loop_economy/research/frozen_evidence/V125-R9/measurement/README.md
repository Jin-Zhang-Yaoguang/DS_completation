# R9 事前固定的只读主指标

`assess_early_sales.py` 不调用候选、不导入官方解释器，不创建新比赛。它消费冻结根 bundle、根的完整 36 局强度评估，以及冻结官方动作审计产生的 24 条 R8/R9 首卖证据。R9 源 SHA 只从以后正式的 `frozen_bundle.json` 获取，不使用待开发源码或自行推定的版本。

调用方式：

```text
.venv/bin/python -B research/r9_cash_prefix/measurement/assess_early_sales.py \
  --plan research/r9_cash_prefix/frozen_bundle.json \
  --first-sale-dir <24条已审计首卖工具v3输出目录> \
  --strength-dir <完整36局冻结assessor输出目录> \
  --output <全新输出目录>
```

上述路径相对 V125 模型根。`--output` 必须为空；已有结果拒绝覆盖。源文件漂移、缺失、重复格或结构错误会留下 failure.json，主指标为 false；不把失败隐去。尚未完成的 R9 文件不应提前传入。

## 主指标保持原预注册

- 固定 1950905901/5902/5903 × 两席 × PASS/V120 × R8/R9，共 24 条轨迹，每个对手 12 条（每版本 6 条）。完整 36 局强度来源另外含 R0，不能少读这项工程前置证据。
- 每局主量是决策 0..239 的真实自产非麦 SELL 现金，含实际肥料出售。零早期销售是合法数值 0；有完全证据的零局始终保留。
- 每个对手独立以 `5 * R9 六局现金和 >= 6 * R8 六局现金和` 判定至少提高 20%；每席的三局现金和不得下降。parent 总和为 0 或任何 provenance PENDING 不自动通过。
- 逐字节校验所有使用文件，重新调用冻结强度工具的纯数据 evaluate，结果须等于根的原评估且 36/36 数据完整性通过。根的 strength_guard 可以为 false，此时仍计算主机制，不能以主机制替代强度。
- 首卖 v3 对 24 条来源全部重新执行只读审计，核验输出一致；任何初始非麦库存、外购来源或物量不闭合仍为 PENDING。不是重新跑比赛。
- 输出每局首卖时刻、完整首卖 basket、早期现金/数量、官方逐日实际观测、G1 原分子/原分母、采购/照护/溢出/终局资产、双方全期现金。候选 `strategy_diagnostics` 只按原样保留为未解释的自报预测，不能称为真实收入。预测字段缺正式时间契约时不臆造“预测命中”。

## 早期费用的完整 0..239 时间窗

种子、动物和商品采购从官方重放 events 的每个真实单位成交价乘数量汇总，day=decision_step//24。BUY_PRODUCT:WHEAT 是实际买麦现金，可能用于喂养或再售；另报真实 FEED 用量，不能把消耗已有库存的机会成本冒充本期现金。

原 runner 的逐日累计市场 ledger 存于观测 step239，覆盖动作 0..238，不直接当成前十日。工具取此累计，再用已核 analyzer 的 recorded_step240 真观测补核动作239：

1. 从原 trace 中截取实际允许的前 maxMarketOrdersPerTurn 个请求。
2. 以前后 unlocked_quadrants 数量变化核实际新增土地，按固定官方 1000/2000/4000 顺序价格求土地费用。
3. 实际原子市场支出 = money239 + 当步真实 SELL 收入 − 当步真实单位采购费用 − money240。
4. 雇工支出 = 上述原子支出 − 土地费用，必须非负整数，并匹配原实际手数起点和允许 HIRE 请求数范围内的 Fibonacci 工资总额。
5. 任一端点缺失、现金无法闭合、未请求却出现费用、土地链异常即 PENDING。不据日末 hands=0 将雇工费用记零。

冻结官方 kaggriculture.py SHA 为 bc8a54879ef02c7ea64b8b333d6a976f0ea65c4949149d01f463f23bccee653e。对应源码：97 行土地原价；548–583 行市场队列/原子订单执行；690–722 行 Fibonacci 工资、雇工与土地扣款；857–883 行日末重置。实际 HIRE 没有 hour23 禁令：23 点能支付工资后立刻在日末移除手。测试保留此反例，不能误用候选自身“hour<8”的雇工偏好作为官方规则。
