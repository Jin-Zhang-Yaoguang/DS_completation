# 首次自生产非麦商品销售计量

`summarize_first_produced_sale_v3.py`只读冻结`analyze_trace.py`生成的官方已存动作审计；策略调用、引擎步进、新比赛均为0。它不判定候选晋级，也不把首卖时间当利润。

计量值为本方首次符合来源约束的真实SELL动作的decision step+1；原始step另报。若整场没有符合条件的出售，完整保留该局并记719。第一笔所处同一帧的全部符合条件销售一起给出品类、数量与现金，并另报第0至9天的实际销售。

当前工具采用比一般FIFO更窄的证据条件：全部非WHEAT产品的初始流动库存均为0，且整局没有对应BUY_PRODUCT；每笔HARVEST/收肥增加自产物量，实际施肥、出售、日终及主动丢失减少物量，任何时点均不能出现负数，末状态与完整官方物量恒等式逐项闭合。因为没有其他来源，实际官方SELL前的仓内物品必然来自自生产，无须猜测同种商品来自哪一个移动批次。仓库与携带之间的搬运不改变总物量；实际SELL由官方逐单位成交事件证明已经入仓。

若出现任何非麦初始库存或外购混入，整场为PENDING，不选择性跳过该商品，也不把买入再售归成生产；如果要覆盖混源策略，必须另写并验证一般批次来源追踪版本。麦被明确排除，原因是当前谱系既生产麦又购买饲料，当前工具不把它们混成生产回款。

输入核对包括原719步审计的所有必要验证项、输出文件SHA、原比赛/轨迹/源码/引擎文件SHA、对应游戏身份、现金终态和读取前后文件不变。缺文件、漂移或重复game key直接失败。没有销售是有完整证据的数值719，来源不明则数值null；两者不同。

示例：

```bash
.venv/bin/python kaggle_Kaggriculture/model/v125_closed_loop_economy/research/r8_terminal_net_selection/summarize_first_produced_sale_v3.py \
  --audit-dir /absolute/path/to/completed_audit \
  --output /absolute/path/to/new_output
```

多个输入重复传入`--audit-dir`。输出目录必须为空。`first_sale.json`给逐局值，`manifest.json`锁全部输入及工具源码。正式阈值由根的冻结开发协议按完整对手块和分席计算，工具本身不声称达成20%或G1/G2/金牌。

首版与第二版工具及其反例结果均保留。v3补齐三个必需审计文件的哈希条目、解析字节与指纹一致性、多输入全局复核，以及严格整数时钟/正整数数量/有限非负价格；任何异常输入不会生成数值通过结果。通过与否以独立复核文件及冻结manifest为准。
