# V55 离线带生成器(开发中,2026-09-08)

目标:自产新代带族,对战口径产出 100k+(现役带 84k,金牌区 95-105k)。
架构:fam_F 前缀(t<72,保路由兼容)+ 配方调度器接管(t>=72)→ 录制为带 → 对战门控。

## 已建成
- scheduler.py:任务分配调度器(收获/浇水/施肥/饲养/补种/买地/雇佣/市场)
- search.py:参数随机搜索管线(14 参数空间,3 seed 并行评价)
- 机制表(实测):farmer=[x,y] NORTH=y-1;tiles[y][x];空地=None;动物 tile
  {animal:"COW",fed_today,cared_today,fertilizer_available,yield_units};HIRE 首价~25(日内 fib);
  雇工当日有效每天重雇;日终随身自动入库;瓜/麦/胡萝卜一次性,番茄/草莓多次。

## 关键架构结论
- 固定预算发单 > 现金守卫(市场单失败无成本,守卫在对战中是自杀螺旋);
- 角色编制(动物/施肥/农耕)消除任务饥饿;划区必须按静态格坐标(动态划区边界抖动致工人震荡);
- 本格任务绝对优先(dist==0 得 -10000 分)是单行最大增益;
- 证伪:价格感知停售(断现金链)、第三象限 d13(负资产)、晚牛(d10+ 不回本)、
  大畜牧配置(劳力抽血)、动态编制、蛇形巡回(被搜索裁决否定)。
- 工具:search.py(随机搜索,噪声 ±8k)、hillclimb.py(8 局对战评价爬山,稳定)、
  audit.py(链路达成率审计)、record.py(录带,跨 seed 衰减仅 6%)。
