# ddah：单独验证新版教师的资金执行修复

使用 Majkel 56216119 的 121 条训练轨迹，保留教师的动物品种和任务；加入销售前置和承诺种子补买。本版不使用 ddy 的动物分配树，目的是单独检验资金执行修复能否改变 ddv 的失败结论。

现有动物依赖编译器不支持该教师大量有意重复的取出请求。例如源轨迹在一个羊、一头牛库存下，同步发出四个单位取出请求，前两个成功，后两个下一步重试。不能把编译拒绝当作教师对战失败。编译诊断保存在 compiler_diagnostic.json，本版直接保留原始动作并做实际合法性投影，不使用未经验证的依赖重映射。

所有筛选均属于开发，未调用 y68 的策略作为候选动作生成器。
