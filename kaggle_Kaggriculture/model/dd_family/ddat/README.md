# ddat：真实销售事件蒸馏

父版本 ddam，保留动物分配、原型35的生产路线、剩余劳动调度和种子补购。改变鸡蛋、牛奶、羊毛的销售控制：从415条教师回放实际成交学习各品类独立的出售分类树及正成交比例回归树，不再默认每步卖尽。

输入：决策前时间、现金、品类库存、总仓储和背包、市场价格和供给、可见商店需求、双方公开动物数和待收产量；不使用对手当步动作、私有状态、未来商店或seed。标签仅采用当步单位动作没有改变该品类仓库库存的记录，避免前后状态不一致。

执行保护：采购动物批次当步、现金低于1000、当前已承诺订单现金不足或采购所需仓储不足时强制释放动物产品；日末根据自身动作后的背包和仓储预留回仓空间；最后一步清仓。融资成本以hires_today计算当天雇佣斐波那契费用。延迟销售不会改写生产路线或调用y68策略。

训练验证按源seed跨教师统一切分，内部验证只用于模型选择。导出树与sklearn概率及回归输出需一致。是否改善竞技能力以同开局完整动态对战为准。
