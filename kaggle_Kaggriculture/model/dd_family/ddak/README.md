# ddak

父版本 ddae。每天从训练回放提取每个单位最后一条非 PASS 动作及最后一次雇佣时刻。只有全部原任务完成、后续不再雇佣时才接管单位，在已解锁农田内最短路安排额外动物采收和照料；跳过教师当日尚有安排的同位置同类动作，单位间目标占用去重。

额外照料需要当天已有喂养或后续已安排喂养，且未来尚有可兑现的原计划采收；不改变作物或已有移动任务。最后一天采收必须预留回仓及 DROP 步数，携带商品临近收盘时优先回仓。其他日次日重置单位位置。当前仓储加全部背包及新采收不超过 95 才新增采收。

这是在蒸馏任务完成后做剩余劳动分配。路径、仓库及报价只读取当前公开可见状态，不使用 seed 或对手策略代码。
