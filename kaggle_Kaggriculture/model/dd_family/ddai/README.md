# ddai

父版本 ddae。保留教师 35 的动作依赖和资金、种子恢复，后续动物品种由回放日程价值规划替代监督分类树。第 0 天采购保持原样。

从训练回放编译 24 只动物的喂养、照料、采收和入仓日程；原物种 161 次采收产量与回放一致。按照真实当期自身动物状态、公开双方动物、当前价格与商店需求，估算三种动物的剩余现金收入；未开放商店只使用官方均匀抽样的期望，不读 seed 或未来实局信息。未来已有对手动物假设每天喂养、照料、采收，未来新增对手动物不预测。

计划比较包含自身商品之间的供应挤压、3% 每日折现和每只 100 的切换余量。更贵物种需在原本当期采购和 100 现金预留之外有足够资金。每天内交易聚合是近似，不是精确价值函数。结果必须以官方动态对战验证。

这版使用了模型化规划，不是新训练的神经网络或 PPO。原动物分类树文件仅保留血缘记录，运行时未加载。
