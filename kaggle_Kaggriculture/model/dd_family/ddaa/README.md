# ddaa：动物分配的反事实收益蒸馏

从 ddy 的教师任务和分配器出发，在开发环境中保持开局、对手和后续策略一致，仅翻转一个动物组的品种选择，跑完整局。标签为这次替换造成的终局胜差变化。教师只提供任务结构；价值标签来自实际模拟器结算。

训练输入仅包含做决定时可见的市场、需求、现金、饲料和动物数量，不包含种子、未来商店、终局现金或对手私有信息。反事实奖励可以使用未来结算作为监督标签；运行时不可读取未来。

该方法是离线反事实策略改进后蒸馏，不称为 PPO 或可调用专家的 DAgger。已完成 20 个基线局和 200 个单次干预局，按 12 个开发种子训练、8 个开发种子验证。选择深度 3 的价值回归树，运行时按估计边际收益决定是否替换为羊。内部验证的单次干预后悔值 1,181，略差于原分配器的 1,144，因此不能把该回归器标为改进；继续用完整组合策略对战检验。尚未产生达标模型。
