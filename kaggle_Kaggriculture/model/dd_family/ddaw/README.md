# ddaw：完整采购组合的开发搜索

保留ddam的原型35生产路线、72步共同开局、预算执行器和销售方式。从第72步开始，对后续11个动物运输依赖组联合选择鹅/牛/羊，保留组内采购、取料、建筑、安置的一致性。每个同回合组合使用一个资金预算，便宜替换释放的资金可用于同时发生的更贵替换。

这是教师任务结构上的完整策略搜索，不是神经网络蒸馏或PPO。候选不读取y68源码或动作，y68仅作为动态对战对手提供整局结算。所有排名来自完整动态对局，不把单次替换收益相加。

先探测919270001..919270128的前72步，按首店8种类别均衡划分8个搜索、16个扩展、16个内部开发验证种子。每个候选的72步观测哈希必须与共同开局相同；所有128个种子都标记为开发，不能进入正式门控/确认。原20个开发开局不包含首店YARN_STORE，不能代表完整首店覆盖。

初始20方案，包括动态基线、原方案、纯鹅/纯牛/纯羊及随机混合。后两轮各20个全新交叉/变异方案；同开局整局胜数优先，均值减半标准差用于同胜数排序。前6个非基线方案在另外16个种子扩展，选择仍属内部开发。共同开局、祖先代码和全部候选参数/轨迹统计保存在joint_production_ddaw目录。

正式资格仍须33对手、双席、两组独立种子通过，固定组合本身不自动算独立成功模型。

## 结果

592局全部完成，源码/数据哈希未变。最优静态方案d0ef4600e608为13/24胜，平均-4421.125，最差-43814；动态基线11/24胜、平均-1997.54。没有晋级或写入默认部署方案。默认production_genome缺省时仍运行父版对照；各实际受测方案在games.jsonl和阶段plan中明确记录并由驱动注入。不能把默认执行器误称为已验证的新强模型。
