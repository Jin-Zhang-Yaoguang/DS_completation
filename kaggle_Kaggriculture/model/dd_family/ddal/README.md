# ddal

父版本 ddak，第 16 天之前保留回放开局与完成后补充劳动。从第 16 天起，原型 35 的每日动作按田块整理为有序任务束，舍弃教师的具体单位编号和移动路径。工人依据当前位置、背包、仓库、作物状态执行最近可兑现任务，资源不足时回仓取料，按尚未完成的任务总需求采购。

相同田块仅一个单位持有任务；过时任务剔除，播种遇到草或未清理作物先整理地块。保留示范每天总雇工目标，实际非投入品库存及时出售，最终日回仓兑现。工资和采购均使用当期真实现金约束。优先级为人工经济估值，任务目标来自训练 replay，不是新训练的神经网络策略。

主要风险是贪心路线与仓库预取造成任务未完成，实际进度偏离原计划后下一日参考任务不再完全适配。开发评估记录 unfinished_tasks、无效请求和实际完成动作，不以离线目标覆盖率宣称成功。
