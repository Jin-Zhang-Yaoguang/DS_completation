# ddw：动物分配的分层蒸馏

教师来源：M & M & P & Q、Majkel 56216119、Artem，共 415 条训练轨迹、6,141 个动物采购订单。按源轨迹分出 1,028 个订单做内部验证。以采购数量作样本权重，训练浅层决策树预测是否选择羊；输入为当时的价格、市场库存、公开需求、现金、饲料和已有动物数量。无未来商店、种子或轨迹身份输入。深度和叶节点下限仅据验证集选择。

执行结构沿用 ddq 的完整教师任务。编译器把采购批次、取出、建造、放置绑定到同一动物组，品种选择在该组第一次动作前冻结。照料、喂养、收获和移动沿用教师任务。原有羊保留，其他动物可改为羊。产物类别随之变化，鸡蛋、牛奶、羊毛按实际仓库数量出售。

离线验证的加权准确率 92.78%，平衡准确率 85.50%，仅表明标签拟合。必须另测动态对战。导出模型概率与训练库逐条一致。
