# dday：番茄和草莓生产程序蒸馏

父版ddam。从同一教师提取52个地块窗口，以官方生命周期做动态规划，保持原移动和服务时点，得到104个种类/采收程序。原始产量397单位与源回放一致。选种使用当前商店延续假设，估计已规划供给和公开对手田块产量；未考虑未来新增商店。

关闭功能时两个719回合动作/现金与ddam精确一致。dev01八局4胜，平均胜差-1977.25，停止扩展。四个单席复核69个选定程序全部播种、无位置偏移；67个产量精确，两个番茄程序各少1单位，合计341预期/339实际。实际损失不能简单归因为种植程序失灵，也包含改变空地后商店随机流的影响。

源码、数据与原run哈希一致；不是稳定胜出模型。
