# ddad：成交后补齐已承诺种子

官方对战发现同一步先买后卖时，前面的种子订单因现金不足被裁剪，后面的牛奶等销售恢复现金，却没有补买。种子缺口导致之后数十个维护和采收任务空转。

ddad 保留 ddy 的任务与动物选择，在原市场订单和动物销售之后，将真实种子库存与教师下一观测的种子承诺比较，仅补齐缺口。剩余市场槽不足时按接下来计划播种的先后购买，每步不超过 10 条。未增加原计划以外的种植，不读取真实未来状态；参考库存是训练轨迹中的任务承诺。

例如旧开发种子 919260010 第 217 回合，少买甜瓜 4、草莓 2 后现金回升至 567；这 520 元的采购缺口可以在播种前补齐。效果须用完整闭环比赛验证。
