# ddam

父版本 ddak，保留基于 replay 训练的动物分配树。在同回合多个采购批次之间共享升级预算，先模拟当前单位动作、可前置的动物产品销售、原始市场采购和已经承诺的种子补购。只有全部原始采购可执行且保留 100 现金后仍有余额，才接受更贵的羊替换，逐批扣除额外成本。

诊断动机：某些败局中父版后期实际动物和作物数持续低于计划；原分类器只决定品种，没有联合约束采购资金。ddai 的价值规划也常被资金条件迫使拒绝升级。因此本版单独验证预算约束，保留原分类决策逻辑，不换成估值优化器。

模拟只使用当前自身可见状态和教师动作；并发对手交易可能改变实际成交价，100 预留不等于保证。记录每次预算、种子预留、原采购短缺和被阻止升级数。
