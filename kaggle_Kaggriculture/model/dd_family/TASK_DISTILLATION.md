# 条件任务蒸馏：ddbe 起

## 数据与训练合约

- 官方 Boey 源回放沿用 ddbd 的 seed 切分：21 训练、7 验证；6 测试未打开。教师队名不等于已知提交版本。
- 训练和验证共 28 条源轨迹，20132 个逐步状态的 farms/private/market/town 与官方 1.32.7 重放精确相等。
- 训练 76303 个成功服务事件，89628 次任务决策（含等待）；不是从 y68 动作学习。
- 每个工人输出目标格、服务类型；数量由独立回归器给出。最短路径执行、目标持续到完成或失效，按较早决策的目标处理预订特征。
- 特征仅有当前可见状态、此前完成的服务和已作出的目标选择。未来成功服务是监督标签，未来观测、seed、身份不是输入。
- 市场模型共享于各订单槽；按官方真实成交生成标签。特征只推进我方订单，保留零成交槽的 WAIT 占位，不包含同回合尚不可见的对手成交。
- 有 1 条训练市场标签在仅我方 shadow 中无法成交，验证没有；记录了此差别，不假装双方交错成交等于单方影子成交。
- 训练是离线监督学习：HistGradientBoosting 二分类候选排序 + ExtraTrees 数量/市场分类回归。推理仅 numpy，四个模型导出与 sklearn 数值核对。

## ddbe

- 候选 247 维特征。100 轮、31 叶的目标排序器；每条正例最多 8 个同动作/同格/随机负例。
- 验证每 32 次任务查询抽取一次，共 920 组完整合法候选，平均 132.41 个候选：Top-1 61.63%、Top-5 91.09%。这只是 teacher forcing，不是竞技能力。
- 32 棵市场分类树，验证准确率 57.53%；数量回归 R2：单位 0.8346，市场 0.6008。
- 开发原4seed×双席×y68v=8局，全负；平均胜差 -183287.125。计时合格、哈希未变。
- 919260010 席0仅发起1次服务，2097次等待。第1天取羊被错判等待，几乎没有生产，之后买卖循环耗尽现金。不能将更高离线指标替代这个失败事实。

## ddbf

- 同数据、同推理接口，重新构造负例，所有非等待任务强制加入 WAIT 负例。
- 正例动作类别的逆平方根频率权重（上限8倍），前3日再乘4，防止开局/安置少数类被维护动作淹没。
- 排序模型400轮、63叶；市场64棵树、balanced 类别权重。920组留出目标 Top1 68.91%、Top5 92.61%；市场验证分类准确率50.31%。
- 开发原4seed×双席 y68v仍0/8，平均胜差-88594.875。初始取羊可正确执行，恢复生产；但取料/放回循环明显，919260010席0有819次PICKUP、453次PLACE，教师成功服务均值约179/68次。
- 另外检查21条教师源首日现金仅1..24，不能单凭学生低现金就归因预算管理。

## 证据

- compile_task_policy.py / compile_task_policy_v2.py：逐步官方回放、标签、因果输入。
- train_task_policy.py / train_task_policy_v2.py：固定训练参数、导出数值核验。
- task_policy_data/ddbe 与 ddbf：源hash、分割、数组hash、编译结果；数据在候选目录之外。
- ddbe/training_report.json，ddbe/runs/development01/summary.json。
- diagnostics/ddbe_teacher_forced.json 与 ddbe_development_audit.json。

当前稳定模型仍0/3。正式全33对手门控和独立新种子确认未使用。

## ddbg

沿用 ddbf 四个学习模型，哈希逐一相等；仅过滤背包已有同类物品时再次取料、刚取料后立即放回仓库的目标。保留真正的动物安置、日末返还。该受控执行修正不自动算另一条独立成功模型。guard行为已核验。原4seed双席0/8、平均胜差-52478.5；平均自身现金从ddbf的51641降至42889，净胜差改善不能解读成自身盈利提升。平均PICKUP从845.5降到288.9，HARVEST从293.5升至387.3。仍低于既有ddam同面板6/8、平均胜差+10379.25。

## 执行归因与 ddbh

对 ddbf/ddbg 四个开发seed的席0，用保存的动作重放，与原719步现金和双方终局回报精确一致；所有成交、雇工、土地现金流守恒。8次诊断重放不算8个新独立开发样本。

- ddbg 四局买入种子355/850/778/1544颗，成功PLANT230/373/191/421次，存在明显囤积。
- 动物逃逸2/5/5/10次，部分发生于中期。计数不自动等于全部错误；末期停止维护可能合理，须按剩余生产核查。
- 当前特征没有直接包含 consecutive_unfed、consecutive_unwatered、pending_care_bonus；不能仅凭模型容量解释所有行为。
- ddbh保留四模型和取放约束，只把每种种子库存上限设为当前工人数，最后回合不买种子；同面板0/8、平均胜差-61198.75；平均自身现金65952.125，高于ddbg，但净胜差恶化，不晋级。源种子价格固定且无供应短缺，囤积的机会成本可单独检验，但不能预先承诺胜率提升。

## 本轮结论

新增32条完整开发对局（四版各8局），12次精确诊断重放不算新增独立比赛。所有候选对局哈希未变、无异常或计时预算超限；0个候选晋级。既有ddam同面板6/8、均值+10379.25显著优于本轮四版，仍保持为控制。三模型目标为0/3，正式门控与独立确认未使用。ddbf、ddbg、ddbh共享学习权重，不能据名字计作三个独立模型。

后续优先调查采购和生产意图的一致性，而非继续将单步分类准确率或自身现金增长当竞技目标。净额化市场前先核查教师同回合买卖的真实现金贡献；不得未经证据删除可能有作用的订单序列。

最终采购链路审计：ddbh四局种子购买降到306/138/204/356，实际播种297/129/193/354，种子囤积基本解决；但前两局动物购买从14/17增至40/46，逃逸从2/5增至30/24，说明释放资金被不受维护能力约束的投资吸收。需联合处理任务、维护与采购，不能继续把资金节约当最终目标。
