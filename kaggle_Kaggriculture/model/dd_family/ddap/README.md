# ddap

父版本 ddn。完整教师请求的忠实转录对照：保留原始单位/市场数量，不按预测库存或现金裁剪，由官方环境执行同回合播种原子校验和双方逐单位市场结算。训练来源仍为同一批 M&M 官方回放；运行输入不读取原 seed、未来状态或对手私有信息。

动机来自闭环复现：原型 124 第 350 帧有两个 WHEAT 播种请求而只有一粒种子，官方取消全部播种；旧执行器逐个裁剪后保留一个，改变后续农场和商店随机流。主用原型 35 未触发此问题，原收益可精确复现。

该版首先是执行语义对照，用于重新判断原计划池，不把保存原始动作表当成独立训练出的强模型。若发生新状态分布下资源不足，原始请求仍可能失效；胜率由完整动态对战决定。
