# ddaj

父版本 ddae。将训练原型 35 的 14 个甜瓜任务编译为固定劳动窗口：移动路线、事件时间与任务结束时空地条件保留。动态规划在这些时段安排短周期种植、浇水、采收、除草或等待；候选 101 个，全部用官方环境单块田结算核对产量、种子消耗和终点空地。

运行时仅在第 6 日及以后按当前公开商品报价选择，估计净值需超过原甜瓜计划 20% 加 20 才替换；种子成本不超过原计划的 80，订单不能挤掉原有市场槽位。补种目标同时扣除已替换的甜瓜并加入未执行的新种植承诺。生成的新商品按实际可用仓储出售，小麦保留教师饲料库存。

估值使用采购时价格和每日 3% 折现，没有预测未来行情；高产量不代表高对战收益。若完全不触发替换，应记为没有有效策略变化，不能当作独立模型。
