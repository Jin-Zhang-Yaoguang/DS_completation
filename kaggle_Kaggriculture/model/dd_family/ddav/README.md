# ddav：蒸馏对手流量的竞争销售估值

复用ddau的已训练单回合外部流量树。用预测市场净流量加回当回合已知镇子消耗，估计对手出售量，再比较现在卖与等一回合的自身减对手收入。

同品类假设三种排序：双方同槽逐单位并发、己方先卖、对方先卖。对每个预测销量分位数分别用官方价格与1元供给截断计算结算收入，跨分位数和顺序求均值减0.25标准差，净差优势超过最低门槛才持有。108种引擎场景已核对结算现金精确一致。

仅用1回合时距，避免把长窗口总销量误当成同时成交。对手真实订单和下一回合新增销售仍未知，三种顺序也没有经数据校准的概率，所以这是近似竞争价值模型，非对手动作预知。市场公开库存已加入逐步诊断，便于后续校验预测。

生产路径、动物分配、资金及容量保护均保持ddat/ddau执行器。属于销售策略同一研发支线，不能因换估值目标就直接计作独立成功模型。
