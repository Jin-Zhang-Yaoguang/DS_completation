# ddaq

教师为新版 Majkel 56216119，与 ddah 同一 121 条训练回放。用官方环境重放双方原动作，记录实际成功的采购、取出、建造、安置与回仓，建立动物身份依赖；单位无效动作改为 PASS，市场无效槽使用零数量占位，保留双方市场订单对齐。规范化数组必须在原回放条件下逐状态精确复现，才能入库。

在这些有效事件上应用既有按源种子隔离训练的动物分配树，并保留 ddam 的当前采购预算和种子恢复。learner 模式和 teacher 模式可匹配对照。真正的变化是此前全部无法编译的新版教师计划获得了可核实的采购—搬运—建造—安置依赖，不把无效请求误认成动物转移。

规范化训练动作的精确复现只证明数据与编译语义。自适应执行器仍会改变动作和时序，竞技能力必须由独立动态比赛验证。三模型稳定目标尚未完成。
