# ddau：回放市场流量蒸馏与滚动销售估值

父版本 ddat，保持生产、动物分配与全部资金/容量/终局保护。出售策略改为市场预测：分别学习鸡蛋、牛奶、羊毛在未来1/4/24回合的市场库存变化，扣除教师自身实际销售对市场库存的贡献。只把决策前可见状态作为输入，未来市场仅用于训练标签。

销售价为1时不增加市场库存，因此不能简单用所有成交数量扣除。提取器用未来观测加回当步镇子消耗恢复售后库存；当售后报价大于1时，证明该回合没有触及供给截断。含自身销售且无法排除截断的窗口不训练；全样本检查外部净流量不得低于纯镇子消耗。

每品类每时距一个回归树，按源seed划分内部验证选深度和叶子数。保存训练叶内加权10/30/50/70/90分位数，用官方非线性价格曲线估计持有后的五种收入；均值减0.25标准差超过立即出售收入及最低收益门槛，才继续持有。每回合重新判断，保护条件可以强制清仓。

局限：扣除自身直接供给并未模拟策略改变后对手的反应；叶内分位数是经验预测，不是保证。当前目标为自身销售收入，尚未显式计入延迟销售给对手报价带来的好处。必须依靠动态对战评估净胜差，不能凭预测误差晋级。
