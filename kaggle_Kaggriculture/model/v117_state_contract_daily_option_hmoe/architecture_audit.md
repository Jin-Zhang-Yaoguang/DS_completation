# V117 架构偏离审计

审计基准：`rs_plan.md` 第 3、5、8、11–13 节。审计对象：已提交的
`v117-r0-balanced-foundation-1`。

| 架构节点 | R0 实际状态 | 偏离 | R1 处理 |
|---|---|---|---|
| 当前合法观测 | 只保留己方与当前市场 | 缺公开对手、市场滞后、终局返仓信息 | 补齐统一状态字段 |
| 统一状态与经济账本 | 仅现金和日期重置 | 缺订单、任务、合同、日级经济与 invariant 事件 | 重写账本与逐 turn 对账 |
| 运行时反馈检测器 | 5 个粗粒度字段 | 缺目标缺口、现金续航、缺粮、市场冲击、切换可行性 | 实现确定性事实反馈 |
| 日级门控器 | 每 turn 重算同一专家 | 不是真正日级，无驻留、滞回、终止和切换成本 | 缓存日合同并实现 Q0 语义 |
| 三个经营专家 | 只有 Balanced | 羊毛与稀缺蔬菜节点不存在 | 实现三套独立合同 genome；未过门专家隔离 |
| 日级经营合同 | 仅 9 个目标字段 | 缺计划要求的大部分合同字段和兑现账本 | 实现完整合同 schema 与不变量 |
| 统一执行器 | 逐 turn 贪心匹配 | 缺任务链、批处理、全局匹配和逾期审计 | 实现 E1/E2 基线 |
| 共享市场与融资 | 固定优先级和当前价 | 缺滞后价格、冲击、现金转化周期和终局预演 | 实现 M0–M3 确定性控制 |
| 安全、恢复与终局 | 仅动作形状校验 | 缺经济语义、现金/饲料/仓容恢复和终局返仓清仓 | 拆分三类控制逻辑 |
| 农场主、雇工与市场动作 | 已形成联合 action | 缺完整语义预演 | 在最终控制器后统一校验 |
| 官方模拟器反馈 | 有 719-call smoke | 缺日级结果与五层研究反馈 | 增加日级结果、失败码和研究快照 |

本次重构不会把未通过资格门的条件专家伪装成“已验证专家”，也不会把本地随机场景结果写成正式
强度证据。
