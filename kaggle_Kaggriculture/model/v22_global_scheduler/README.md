## 关键机制发现
- **估值价陷阱**：task_value 用瞬时市场价会被对手砸价带偏（对战中放弃草莓管理）；
  改用 max(现价, 0.8×BASE) 下限后对战产出恢复（167）、单人再 +0.8k。
- 动物任务需要 ranch_bias≈6 的先验权重（纯金币价值会低估断喂的链式损失）。
- 小麦（178/564）在全局排序下天然排队尾；抬其价值（v_plant_coef 3.5-7）全局变差——
  当前劳力预算下低配小麦可能就是正确取舍，CornHub 的 564 出自更高的动作效率富余。
