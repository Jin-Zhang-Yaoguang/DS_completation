# V80 假设：空间物流—劳动力容量 Hierarchical MoE

## 第一性原理

生产计划的名义产能不等于执行产能。一个执行单元每回合只能做一个动作；当完整路线给出 PASS，而该单元脚下恰有需要维护的作物或动物时，这个空闲槽位是可观测、不可追回的劳动力损失。

## 单一因果杠杆

每个执行单元独立路由：父动作不是 PASS 时严格保持 V76；父动作是 PASS 时，仅根据当前位置、脚下 tile 和该单元私有携带物，选择 WATER、FEED、CARE、COLLECT_FERTILIZER 四个本地维护专家之一。Router 不移动单元、不改变买卖或生产数量，也不跨单元转移任务。

## 与既有谱系的边界

V54 只在终局把携货单元改道回仓；V80 在全局 720 步内利用闲置劳动槽，但不做终局清算或市场排序。V80 复用 V76 的状态安全执行器、商品出售控制器和对手路径机制。

## 可证伪预测

- 相比 V76，应在真实局中产生广泛但局部的动作变化。
- 若空闲维护是有效瓶颈，额外 WATER/FEED/CARE 应提升未来产出，且不增加灾难局。
- 若开放路线故意用 PASS 保持日程同步，工作窃取会破坏后续 choreography，POU 将显著为负并被 Development 否决。
