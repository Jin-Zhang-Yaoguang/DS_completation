# V112 预注册：恢复专家流形 Hierarchical MoE

八条完整生产 continuation 先共享同一 216 步前缀，并使用相同的状态恢复执行语义，从而形成可比较的专家流形。高层 Router 只能使用 step 216 的前三商店、席位、双方现金和劳动力状态，按 seed 隔离 OOF 选择一个 continuation 并整局承诺。

来源资格使用 32 个 synthetic seed、V20/V76、双席位、8 个专家，共 1,024 场。Router 必须相对聚合得分最高的固定单专家 `BEU>0`、正翻转多于负翻转、灾难率不恶化超过 1pp；否则记为专家支配，不构造。研究探针可复用历史恢复执行器生成专家标签，但最终候选必须独立实现且禁止完整历史 agent 依赖。
