## 原创性与失败机制

- V77 的 Router 逻辑成立，但完整专家强度差距过大；需求匹配无法补偿弱生产路线。
- V78 把对手资产存量误当下一市场槽行为，信念没有校准，错误抢跑破坏既有精确排序。
- V79 的风险条件在 768 个配对单元中从未产生动作变化，说明该联合偿付冲突不是 V76 的现实损失面。
- V80 是唯一值得保留研究价值的方向：它直接对 V76 提升 15.63pp，但对 V32、V54、V66 明显退化，说明执行 choreography 存在可挖增益，却需要可恢复的日程状态而非无状态工作窃取。
- V81 证明“精确求解”不能修复错误预测；父队列不是跨谱系稳定的对手响应模型。

## 下一批优先级

1. 保留 V76，不提交 V77–V81，也不修改 `golden_model.md`。
2. 优先研究“可恢复 choreography”：维护动作必须同步修改后续任务状态或在可证明冗余的 PASS 槽中执行，先解决 V80 的对手依赖。
3. 对手路径预测先做可识别性和概率校准；没有逐商品 next-slot 准确率、置信回退和离线 calibration，不再接入市场执行器。
4. 生产 MoE 只允许同强度、状态兼容专家进入 Router；先做专家资格门，再讨论需求路由。
5. 商品 MPC 改为不依赖单一路径预测的鲁棒情景优化，并把模型误差成本显式纳入目标函数。
