# Kaggriculture 环境与策略要点

> 本文整理自 Kaggle 官方 How to Play、Evaluation 与 Getting Started 页面，供实现 Agent 时快速查阅。

## 默认环境

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `episodeSteps` | 720 | 24 回合 × 30 天 |
| `boardSize` | 10 | 每位玩家的 10×10 农场 |
| `startingMoney` | 3000 | 初始金币 |
| `maxMarketOrdersPerTurn` | 10 | 每回合最多处理的市场订单数 |
| `turnsPerDay` | 24 | 每个游戏日的回合数 |
| `shedCapacity` | 100 | 仓库中非种子物品容量 |
| `weedSpawnChance` | 0.005 | 空闲已解锁地块每日生成杂草的概率 |

## 可见状态

Agent 每回合主要接收：

- 当前玩家编号、游戏日和当日回合。
- 双方公开农场状态：金币、地块、农民与临时工位置、已解锁象限。
- 共享市场：各资源库存与当前价格。
- 共享城镇：已经解锁的商店及其需求。
- 自己的私有状态：仓库、种子以及农民和临时工随身库存。

对手的农场和金币可见，但其仓库、种子及随身库存不可见，因此环境具有部分可观测性。

## 动作空间

### 农民与临时工

- 移动：`NORTH`、`SOUTH`、`EAST`、`WEST`
- 作物：`PLANT`、`WATER`、`FERTILIZE`、`HARVEST`
- 动物：`PLACE`、`FEED`、`CARE`、`COLLECT_FERTILIZER`、`HARVEST`
- 地形：`BUILD_COOP`、`BUILD_PASTURE`、`DIG`
- 仓库：`PICKUP`、`DROP`、`PLACE`
- 空操作：`PASS`

### 市场

- `BUY_SEED`
- `BUY_ANIMAL`
- `BUY_PRODUCT`（仅可购买小麦与肥料）
- `SELL`
- `HIRE`
- `BUY_LAND`

市场订单与地块动作可以在同一回合提交；默认每回合最多处理 10 个市场订单。

## 生产规则

- 作物若连续两天未浇水，会变为杂草。
- 新种下的作物必须在种植当天浇水，否则当晚即可变为杂草。
- 动物若连续两天未喂食，会永久逃走；动物以小麦作为饲料。
- 小麦、胡萝卜和甜瓜属于一次性收获作物。
- 番茄和草莓可以多次产出，但具有有限生命周期。
- 动物会持续生产，但必须安排喂食、照料、收获与肥料收集。
- 每日结束时，农民和临时工会将随身物品放入仓库；超出容量的部分会丢失。

## 地图与劳动力

- 10×10 地图分为四个 5×5 象限，初始仅解锁一个象限。
- 后续三块土地的默认购买成本依次为 1,000、2,000 和 4,000 金币。
- 临时工通过 `HIRE` 购买，只在当日有效；同一天连续雇佣的价格按 Fibonacci 序列增长，并在次日重置。
- 农民和每个临时工每回合均可获得一个动作，因此路径规划和任务分派直接决定生产吞吐量。

## 市场机制

- 种子和动物供应无限且购买价格固定。
- 商品出售价格随共享市场库存动态变化，价格最低为 1 金币。
- 双方订单逐单位并发处理，因此大额订单内部也可能经历价格变化。
- 城镇中心与逐步解锁的商店会定期消耗商品，为不同资源制造外生需求。
- 高价值商品在供给过剩时可能快速跌至价格下限，不能只按基础售价估算收益。

## 直接影响策略的评测特点

1. **胜率优先于利润差额**：评级只看胜负，因此稳定以小优势获胜通常比偶尔获得极高利润更重要。
2. **动作也是稀缺资源**：生产收益必须扣除移动、照料、收获和搬运占用的回合。
3. **现金流不能只看库存价值**：未卖出的产品不计入最终成绩，并且仓库存在容量上限。
4. **市场会被双方共同改变**：固定的单一作物脚本可能因对手同质化生产而失效。
5. **长期投资存在截止风险**：土地、动物和持续产出作物必须在剩余赛季内回本。

## 推荐的实现顺序

1. 完成可运行的确定性规则 Agent，并通过自身验证局。
2. 实现状态解析、合法动作保护和日志记录。
3. 完成基础种植闭环：买种子、移动、种植、浇水、收获、入库、出售。
4. 加入路径规划、每日调度与临时工任务分配。
5. 建立资源级现金流和剩余赛季回报模型。
6. 加入动态市场时机、城镇需求和对手行为特征。
7. 在可靠基线之上尝试搜索、策略混合或强化学习。
